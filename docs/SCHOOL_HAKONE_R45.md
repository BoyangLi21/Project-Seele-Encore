# R45 学校与箱根站候选交接

本子任务没有写入世界，没有启动 Minecraft 或 build；模型、动画、交通身份和共享源码均未修改。Root 已串行施装 `school_v2` 主批和 `hakone_v5`；原生动作、光影照片与最终实际安装副本回读仍由 root 执行。不能把候选、静态路径或离线体块图改写为发布质量通过。

当前唯一续建/派生入口为 `artifacts/rebuild_r45/school_hakone_agent/lifecycle_v2/handoff.json`。主批不重放；`school_tail` 仅当前实测236格（234格完整操场护网/庭院低植栽座椅、2个实际墙面的中文原生指路牌），保护当前313份学校完整BE，新增2份sign NBT。旧完整候选和首份delivery manifest仅作证据；未完成的school_v5/manifest_v2尝试不得选作施工输入。生命周期目录已补齐独立体育馆全楼面，共9个学校楼面范围。

## 原作与现实资料的采用边界

- 学校两条三层教室楼、连接空间、楼梯塔、屋顶和体育馆关系继承 R44 已核对的[官方 SMALL WORLDS 报道](https://www.eva-info.jp/6649/2)。这是二级模型造型参考；本子任务没有观看完整 TV 集数或取得官方校舍平面。房间数量、尺寸、选址、家具和泳池25×10米均为原创工程选择，不称逐帧或1:1还原。
- 现实箱根站选择箱根湯本 OH51，核对了[小田急站点资料](https://www.odakyu.jp/station/hakone_yumoto/)、[完整立体构内图](https://www.odakyu.jp/station/hakone_yumoto/homeview/)和[小田急箱根运营方楼层/站台/巴士图及说明](https://www.hakonenavi.jp/transportation/station/hakone-yumoto/)。立体图标注2025-10-25，平面资源标记260303。资料通过浏览器实际查看，只用来核对空间关系，没有加入游戏资源。
- 现实是一层三种平台用途（Romancecar、小田原普通、强罗登山）、二层单闸机/服务与跨路公共桥，包含真实楼梯、扶梯、电梯。候选采用公共服务用途、平台与转乘区分、长雨棚和站厅细节。
- 现存游戏交通是两套不同高度的高架线、四个方向平台、四组下层闸机。为了保留运行身份/实际外部接驳，候选沿用该拓扑。高度、轨数、闸机层位、屋顶形状、房间尺寸和用地都与现实不同；无官方测绘尺度，不宣称1:1。现实电梯、跨街巴士设施没有对应运行装置，因此保持未实现，而不是搭假井道后计为功能完成。

## 精确施装方法（仅 root 执行）

1. 从 `lifecycle_v2/handoff.json` 读取当前236格尾差与派生计划，逐项校验冻结 SHA；使用当前 `SEELE_FIELD_R45_REVIEW`，不得再施装8170格学校主批或27261格箱根主批。
2. 客户端关闭/世界锁持有期间，经 `query_blocks.py` 回读每个正向坐标，完整 state 与 `before_nbt` 逐项相等；校验 `preserved_block_entities.json` 的全部状态与原完整 SNBT。若变动，调查来源后重新冻结差量，不强行覆盖。
3. 根目录下可使用现存 `regional_voxels.Painter`：每行 `match((*pos,*pos), before, after, owner)`；所有非空 `after_nbt` 用 `nbtlib.parse_nbt` 放入 `block_entities[pos]`。候选另给 `root_operation_plan/ops.json.gz` 和完整新增 `block_entities.json`。只有 root 设置 `v.WORLD`、`v.OUT` 并调用 `Painter.apply`。
4. 不使用 `install_frozen_city_delta_r44.py` 的静态无BE分支；它明确拒绝新增完整 NBT。该批必须走完整 NBT 施工接口。
5. 世界写入后回读全部真实方块/新旧BE，并分别检查交通文件、玩家/任务/NPC/机体进度。不得从 QA 世界整包复制交通或进度。
6. `forward.jsonl.gz`/`inverse.jsonl.gz` 为一一对应完整数据；`positive_edit_mask.jsonl.gz` 是精确写入集合。原生加载可能加入 `keepPacked`、更新时钟或邻接状态，因此实际回退以 root 的 apply 收据/本地 before 区块和最新完整 NBT 前置检查为准，不盲目回放理论 inverse。
7. 箱根 `path_replacements.json` 包含五条派生路线的前后内容：S1北图板起点移到真实闭闸外、四条旧岛台中心线绕开 X-1481 原指示柱。保留原端点、原设备和旧失败证据；对实际当前路线目录逐项按旧内容匹配后更新，禁止换掉整包目录。

## 已安装后的生命周期与调用链

`derived_file_plan.json` 保留当前20,685条原路线记录及其顺序/无关字段，只修改上述五条已核对路径，再追加本轮全设施义务；两个新文件是 `r45_school_hakone_components.json` 与 `r45_school_hakone_navigation.json`。新导航文件绑定完整组件与最终路线 SHA，未冒称产生已验证navigation mesh。临时 `r44_walk_cases.json` 正在被root使用，不合入或替换它。

`author_school_campus_r45.py` 与 `author_hakone_station_r45.py` 新增 `--repair-current`；发现已施装收据或R45组件目录时，自动进入当前实测尾差/派生流程，不能再把旧课堂或整站顶棚当初始空地重放。原学校三专用R44脚本已加退休guard，默认明确拒绝当前维护；`--historical-r44` 只为历史证据。共享 `plan_new_city_blocks_r44.py` 的学校分派点需要root应用本目录 `shared_school_dispatch_guard.patch`；子任务按边界没有改共用工具。它只拦截 `kind=tv_school`，其他街区与美里分派保持原义。

`canonical_templates` 保存R45确定性目标及不可回放/人工修改保护规则。当前维护须保留实际完整NBT和交通身份，跳过不满足已测前置的人工改动；新世界不能仅用一份差量冒充完整学校，需要完整v22结构与R45目标组合后由root建立新的测量前置。

`ecology_additions.json` 的五个有限体积已交地形代理，作为它唯一全图provider的强制并集输入。保留source/worldpack各自原552前缀/自有设置；现存worldpack的fixed codec不能仅加一个被忽略的 `protected_volumes` 字段后宣称保护完成。Root必须安装地形代理最终合法codec候选，冷加载后验证实际 `protectedAt`、`permitsVegetationAt` 和完整staged-feature拒绝，确认新泳池不会被植物覆盖。

`native_review_order.json` 按形状→全室楼面→实际32扇双格门（64往返）→双塔/屋顶→泳池完整操作→八闸→全站服务换乘→四平台368个逐个上车端口→全部shader照片→生态冷加载排队。实际回读目录另列学校32扇普通门/538个设备、站内16扇普通门/368个MTR APG下半门叶/319个设备；APG是自动列车联动装置，不交给普通 `useDoor` 测试冒称开门/上车。
