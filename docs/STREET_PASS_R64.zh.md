# 街道设施与巨型机体（R64）

第 511 批在第三新东京市地表放了电线杆、电线、变压器箱、警报杆、避难所亭和静态红绿灯，共 31,789 格。这批设施会把初号机抬上杆顶，再把它卡在电线上，悬在街面以上约 7 格；萨基尔跨步只有 2 格，会被直接挡住。测试记录见 perf 2026-11-18 的报告。

这里有两样东西，各管一件事：

1. **可穿过清单**（`street_pass_r64.json`）：巨型机体在任何高度都不和清单里的格子碰撞。城市升起和降下两种状态都有效。
2. **城市降下时收起设施**：把这批设施加进现有的街面设施表 `battlefield_r21.json`。城市停稳在降下（战斗状态）后设施换成空气，升城前放回去。

只用第 1 样也能走能打；第 2 样让战斗时的街面干净，可以不用。

## 可穿过清单

代码：`world/StreetPassR64`（读清单、发给客户端、查询）、`world/StreetPassCellsR64`（按 16³ 区块存的位图，以及发送用的压缩格式）、`network/ClientboundStreetPassR64`。

- **谁能穿过**：初号机这类 EVA（`EvaObstacleCollision.ignores`）、使徒（实现 `Angel` 的实体）、量产机。人、车辆和其他实体照常碰撞。
- **哪些格子**：清单里的格子，并且当时的方块是清单 `blocks` 里列的一种。地图以后在某格盖了别的东西，这一格就恢复碰撞。
- **不受影响的情况**：后勤锁定和出击过程中的机体照常碰撞，和原来的规则一样。
- **跟着生效的地方**：新旧移动模型画脚时找地面、斜坡探测、贴墙姿势都经过 `EvaObstacleCollision.ignores`，所以脚不会再踩到杆顶上，也不会把电线杆当墙。
- **两处没跟着生效**：`EvaUnit01Entity` 里的 `dropAtR64`（新模型的边缘探测）和 `EvaTerrainSupport.height`（趴下时的地面）各自做射线，没有经过这个规则。这次没改这两个文件，影响是趴在杆子上时贴地面的姿势可能参考杆子。
- **客户端**：玩家驾驶时机体的移动在玩家客户端上算，所以服务器在玩家登录、换维度、重生时把清单发过去。3.2 万格编码压缩后约 3 KB。网络协议升到 82。
- **服务器读取时机**：开服后第一次用到这个维度时读世界根目录的文件。文件改了要重开服务器才生效。
- **清单坏了**：日志写一行错误，然后当作没有清单，机体照常碰撞。

### 清单格式

```json
{"schema": "projectseele.r64.street-pass.v1", "dimension": "projectseele:geofront",
 "blocks": ["minecraft:andesite_wall", "minecraft:chain", "..."], "count": 31802,
 "cells": [x, y, z, x, y, z, "..."]}
```

## 收起设施（可选）

`BattlefieldR21` 原来就有这个机制：城市停稳在降下后，把表里的格子换成"收起"的方块，升城前放回。工具会把第 511 批的格子加进这张表：展开时是它原来的方块，收起时是空气，告示牌连同文字一起记下。

这次还修了一个顺序问题。R45 城市收到升城请求后，要先排队，等几刻或更久才真正起步。排队期间，旧的城市记录仍然写着"停在降下"，于是刚放回去的设施又被收了一遍，城市升起后这些设施（原来那 5,066 格）都不在。现在 `BattlefieldR21` 还要看 R45 城市自己的状态，城市停稳在降下时才收。**扩展后的表只能配有这个修正的包一起用。**

## 第一战行军迈不上路缘

`SurfaceAngelAssaultR52` 让萨基尔沿第一战路线走时，AI 是关着的，每刻只做水平移动。这样实体一直不算"着地"，而原版的抬步要求着地，结果它连 1/8 格高的路缘坡都迈不上。TrafficCraft 修路以后，路线上 z=36 就有一排这样的路缘：即使街道设施都能穿过，它也会停在 z≈27。

现在行军的一步抽成了 `marchStep`：步行的使徒每一步都带一个和一刻重力相当的向下分量（0.08 格），这样它站在地上，能像正常走路一样抬步。飞行的水天使不变。测试探针直接调用这个方法。

## 怎么做清单（写入会话，世界停着）

```
python tools/street_pass_cells.py --world <世界> --rows E:/eva-map-buildings/plans/t4-street/rows.json --extra tools/street_pass_extra_r64.json --out <新目录>
```

输出四个文件：

- `street_pass_r64.json`：复制到世界根目录。
- `battlefield_r21.json`：只在要做"收起设施"时，覆盖世界里的同名文件。
- `cover_rows.json`：世界正处于"降下、设施已收起"状态时才有内容。用 `tools/write_deep_cells.py --allow-block-entities` 写入，让世界和表一致。
- `report.json`：统计。

规则：

- 设施行里的格子，只有世界里还是那一行写进去的方块才会收进清单。被拆掉或改过的自动跳过（例如武器楼门前清掉的 152 格）。
- `tools/street_pass_extra_r64.json` 列了萨基尔第一战路线上的 3 丛矮树和 2 盏路灯，它们也挡萨基尔。只让巨型机体穿过，方块留在原处。

map-buildings 以后改动设施，要重新跑一次这个工具。
