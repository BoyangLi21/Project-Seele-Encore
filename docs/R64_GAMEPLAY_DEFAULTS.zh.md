# 初号机的移动和战斗模式

此切换提交把新配置中的初号机移动设为 `planted`，战斗设为 `frames`。已有配置会沿用原值。联机以服务器端选项为准。

| 操作 | 指令 |
|---|---|
| 查看当前移动与战斗模式 | `/seele motion`、`/seele combat` |
| 使用落脚步态与按帧判定的招式 | `/seele motion planted`、`/seele combat frames` |
| 恢复旧移动或旧战斗 | `/seele motion legacy`、`/seele combat legacy` |

两个选项可以独立切换。试用时可先在机库完成一次出击，在平地站定、连拳、松键和走停，最后进入屋岛流程，检查搬运、就位和射击衔接。此分支单独保留，默认值并入发布候选的时间由负责人决定。
