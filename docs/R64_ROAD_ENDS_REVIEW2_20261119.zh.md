## 文件与复验

- `batches.json` 列出各区域的 MD5、维度和写入参数。`rows.json` 为去重完整表，`decisions.json` 为逐项判定。所有 XYZ 均属 `projectseele:geofront`。
- `strict-grades.json`、`actual-connections.json`、`review-centres.json`、`six-sites.json` 和 `owner-access.json` 记录坡度、实铺路线、住宅门及站台；`rescan*.json` 记录主图复扫。
- `preflight.json`、`postflight.json`、`installation.json`、`crosscheck.json` 为实际写入和交叉复核。建图时的旧街与低层证据留在 `baseline/`。
- `views/comparison-1.png` 至 `comparison-4.png` 为两个指定工区、#236 和雾里跨水桥的原始与试写后俯视；`grade-编号.png` 含四处短坡及 #215；`site-编号.png` 展示局部道路验收。

在包含项目 `tools/` 依赖的 Python 环境中运行以下命令。每批均使用一个新备份目录。

```text
frpy tools/verify_road_end_batches.py --world <冷副本> --index <交付>/batches.json --expected old
frpy tools/write_deep_cells.py --world <试写副本> --rows <交付>/rows/<区域>.json --out <新备份目录> --refresh-heightmaps --allow-block-entities
frpy tools/verify_road_end_batches.py --world <试写副本> --index <交付>/batches.json --expected new
frpy tools/verify_road_end_grades.py --world <试写副本> --centres <交付>/review-centres.json --id r1-391 --id r1-392 --id r1-236 --id r1-352 --id r1-215
```
