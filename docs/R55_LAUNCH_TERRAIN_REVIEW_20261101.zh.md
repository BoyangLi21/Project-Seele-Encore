## 尚未解决的道路问题

全图发现不能等同于整张地图已经合格。材料扫描包含屋顶、墙帽、院落边界和多层道路；不能把它们全部当作应连接的街道。当前另有道路端部与坡道接口需要继续判别和设计，完整证据保存在本轮 `road-recovery`：

- `survey.json` / `observed.npz`：全部实测材料层，包括被埋路面。
- `classification.json`：当前道路、仍在使用的旧路、退休旧路和未分类材料。
- `verification.json`：保护体积、已认领道路和新回填接触位置。
- `carriage-terminals.json`：机动车道候选端部，与窄步道、建筑入口分开；候选数量不等于错误数量，也没有标成全部通过。
- `connections.json`：成功连接及未强行直连的接口。遇到另一层道路、原结构或高差过大时保留现场，交由有完整断面的道路设计处理，不另加悬空桥板。

新旧地图接边的后续工程仍需统一道路标高、支撑、有限设施和山体过渡；本轮发射区整坡不能替代全域完成。所有检查均离线执行，没有增加游戏运行时检查或等待门槛。
