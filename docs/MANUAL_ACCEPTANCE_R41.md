# R41 安装与验收

发布状态以同批 `RELEASE.json` 为准。Minecraft 1.20.1 / Forge 47.4.10 / Java 17，协议 44；客户端与服务端应使用同一批 R41。

本轮从实际试玩过的 `SEELE_R40_WORLD` 保存进度继续。金字塔原大指挥室布局、原机体和插入栓身份、完成的任务、玩家与列车资料均保留。机械流程在单独的测试副本中运行。

## 安装

- **Client.zip**：拖入 PCL，创建 `Project SEELE R41` 独立实例。模组、模型、世界、材质和光影已内置。PCL 只可能补齐缺少的 Minecraft / Forge 基础运行库。
- **Server.zip**：解压后，把 **World.zip** 的内容放进 `SEELE_R41_WORLD` 文件夹，确保其中直接包含 `level.dat`。确认 Minecraft EULA 后设置 `eula=true`，用 Java 17 运行 `Start-Server.bat` 或 `start-server.sh`。
- **World.zip**：独立存档。手动装入客户端时放进 `saves/SEELE_R41_WORLD`。
- **Shaders.zip / Textures.zip**：独立备份；Client.zip 已有同一份文件。

原 PCL R40 实例保留。本机开发入口为 `D:\eva\start_eva_test_r41.bat`，进入新的 `SEELE_R41_WORLD`。加 `--check` 只检查启动条件，加 `--no-shaders` 临时关闭光影。开发入口共用源码运行目录；需要完整回退时使用原 PCL R40 实例或原 R40 整包。

建议客户端分配 6–8 GB 内存。光影仍是包内已固定的 `ComplementaryUnbound_r5.3_SEELE_R39.zip`；文件名沿用室内补光版本。实例内 `Enable-Visuals.bat` 直接选择该文件，无须再次下载。总指挥席后拉杆控制指挥室灯具。

## 先检查这三个位置

1. `95 -442 -44`：候梯厅南侧边界已补齐，站厅与电梯之间的地板接缝也已处理。沿整个厅边走一圈，检查临空处及门前通行。
2. `105 -391 -42`：旧扶梯的伴随墙体已经清除。检查现有走廊外侧及上下层视野。
3. `86 -394 -270`：自动步道的两格出口均已打开。两条带分别走出，再反向走回。

管理员可在当前维度使用以下安全落脚点附近查看：

```mcfunction
/execute in projectseele:geofront run tp @s 95.5 -442 -45.5
/execute in projectseele:geofront run tp @s 104.5 -394 -45.5
/execute in projectseele:geofront run tp @s 84.5 -394 -269.5
```

随后检查金字塔四层东侧接口、机库登机栈桥、Dogma 回廊、地表楼梯井、车站前广场和港口岸线。新护栏位于方格边缘；楼梯的三格宽度、原生自动步道及列车通行空间按各自用途处理。

## 电梯、栈桥和导视

- 在机库电梯外呼叫轿厢，实际走过门槛进入，再乘坐至另外两层。观察轿厢离开时层门是否关闭。
- 沿初号机登机通道走到插入栓，面向舱口进入。美里、律子自动执行整备与发射；观察栈桥及护栏一起收起。
- 回到原地表舱口，通过电话回收。待回库后检查登机栈桥重新展开，周边没有遗留在空中的护栏。
- 在不同楼层读取指挥室、机库、车站指引，再按指示走至电梯和目的地。
- 金字塔接驳站路线的终点现位于黄线后的候车区。站台固定玻璃与列车门各自保留原有作用。

导航现在检查节点间的实际碰撞边界；最终包内的 `nerv_routes_r24.json.gz` 必须与发布清单哈希一致。上一批漏带新导航缓存的问题已列入交付检查。

## 动作与交战

分别用初号机、零号机、二号机、UN-00、UN-01检查：

1. 原地站立 → 蹲 → 趴 → 前爬 → 起身，中途反向切换一次。看髋、膝、踝是否翻转或跳变。
2. 靠近查看左右手。趴姿的掌面和手指应随同一套骨架变化，手指不能竖起或脱离；持枪时检查握把、托枪手与扳机手指。
3. 原地下降到膝部承重姿态，听关节负载与实际膝部触地声，再起身。
4. 与萨基尔贴身交战，分别在站立、蹲姿及趴姿受击。检查推击、拳击、下砸、踩踏和腕部突刺的接触位置。
5. 连击后移动，做跳击，再被击倒并恢复控制。普通移动与受击恢复应能接回当前要求的姿态。

操作延续原版：WASD 移动、Ctrl 跑、空格跳、Shift 蹲、Z 趴/起身、左键普通攻击、右键重击、R 切换已持有武器、G 力场、逗号键抓取/投掷、V 脱离、O 驾驶中联系指挥室。

伤害、基础血量和冷却未因本轮姿态修复调整。实际接触修正可能改变一次交战的有效命中次数。具体工程结果与原生媒体以发布记录为准；动作手感、音色及美术仍请结合实玩评价。
