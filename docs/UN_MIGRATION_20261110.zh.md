# UN 基地整体迁移（2026-11-10）

负责人睡前授权“GeoFront / UN 迁移等等，不需要我的允许”，主会话决定整座基地作为一个刚性整体平移。2026-11-10 已装入正式世界，第 371–378 批，等负责人统一验收。审计和代码改动见主会话的 `UN_MIGRATION_AUDIT.md` 与主干提交 0220638a。

- **为什么在海上：** 小田原预留地里找不到能整座放下的位置（审计已证明），所以选在小田原近海。三个偏移都是 16 的倍数，整个区块柱可以原样搬动；旧址旁边的海面 y 62 平移后正好落在小田原海面 y -82 上，和港口当年用的 dy 相同。
- **选址测量：** 依据实测地表，新址范围内没有铁路，陆地只有西北角 3,052 列海滩。

## 做法

工具：`tools/move_un_base.py`（区块、实体、数据、MTR、偏移五个阶段）和 `tools/plan_un_trim.py`（削山、海堤）。

1. **区块（第 371 批）：** 3,048 个区块整块平移，区段 Y 整体下移 9 段。方块实体坐标和站牌 `PlatformCentre` 一并平移；光照清空后由游戏重算，高度图丢弃后由游戏重建。旧址西北角 48 个没生成完的区块不搬。搬之前检查过目标区块里没有任何已建方块。
2. **实体（第 372 批）：** 314 个实体全部带原 UUID 搬到新的实体区域文件，并在同一步从旧文件删除。平移的字段：`Pos`、EVA 的 `UNHome*`、NPC 的 `StaffStation`、插入栓载具的 `Field*` 和 `CanonicalTranslationR53*`。这份字段清单来自对旧址全部实体和方块实体的扫描，没有遗漏的坐标字段。
3. **数据（第 373 批）：** 10 个世界根 JSON 里落在旧址范围内的坐标全部平移，站位 id 不变：`r52/travel.json`、`regional_boarding_gates.json`、`r44_public_station_gates.json`、`nerv_staff_r15.json`、`ROOT_MECHANICAL_OWNER.json`、`r07_installations.json`、`regional_plan.json`、`un01_annex_r20.json`、`un_hangars_r31.json`、`facility_lighting_r30.json`。存档数据：`un_locations_r22` 的 4 个位置、空运载台 `CartPos0/1`、SBW 预载区块表的 92 项。`un_air_reception_r40.json` 保持原坐标，由代码加偏移读取。
4. **MTR（第 374 批）：** 13 段机场轨道、1 个站台、1 个车站平移，id 不变。MTR 按两端坐标的带符号字典序给轨道命名，有 5 段的 z 跨过 0 后换了顺序，工具已按这个规则重新命名。航线路径用 MTR 引擎重新生成，验证通过（飞机实际飞行）。
5. **削山和海堤（第 375–377 批）：** 旧址框里连带的天然山坡，凡高出基地平台 3 格以上的都削到平台高度，共 39,453 列；外沿的陆地列改成石砌海堤，共 2,522 列。只动天然地面、树和植物，没有动任何建筑。
6. **偏移（第 378 批）：** 最后才写 `projectseele_facility_sites.dat` 的 `UN_BASE`，`PORT` 保留不变。顺序反过来的话，机库门会在真门旁边重复生成。

## 验证

正式安装前，在副本上先完整跑了一遍，并进游戏测试（测试客户端用含主干代码 0220638a 的 jar）：

- **机库门：** 一次完整开合，依次是关闭中 → 干燥/关闭 → 开启中 → 允许出舱。
- **空运：** 投送 UN-00 到小田原 (3532, 34, 350)，再回收到新址库外接应平台。下一步“平台送回机库”是正常流程，没有继续测。
- **其他：** `/seele tp un_hangar` 能到达新机库走廊；F2 飞机在新机场站位停靠并开门；61 名 NPC 都在岗位，距岗位 0 格。日志里没有 `Duplicated UUID`、`UN receiving apron could not load` 或人员名单报错。
- **测试指令：** `/un` 和 `/seele military` 只接受玩家本人发出的指令，所以测试时先给测试玩家 OP，再由玩家发送。

正式世界装完后独立比对：291,777 个搬迁区段逐格与备份一致，差异只出现在 778,356 个削山和海堤格子上；新址 314 个实体，旧址 0 个；新址 13 段机场轨道，旧址 0 段。
