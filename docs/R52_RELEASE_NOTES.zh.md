# R53 本轮地图迁移说明

本批为代码审查完成、运行尚未验收的私有版本，供负责人恢复人工检查。当前实际试玩存档的角色、交通与未完成整备进度继续保留；不重置进度来制造通过结果。

本轮范围为 1／2／4，前批完成的非地图修改保留。三机体、原插入栓、驾驶员和职员继续使用原身份。玩家、任务和交通进度从冻结正式试玩源迁移，没有导入旧失败 R52 地图或测试进度。

- 九条实际发射孔道、衬墙、钢轨和机构接头使用当前坐标。三个准备区相邻，发射段没有水平长段。
- 排液、维修坑、原登机桥、机械门和地板密封继续联锁；取消整备沿实轨返回原机库。
- 出口／回收分别绑定地下地表、原城市井、箱根；空运使用原有两架 NERV 飞机及共用升降井。
- 电流爆发与轨道摩擦音效为原创合成，火花绑定真实轨道接触点。
- 本轮必要旧设施、外接台与旧指令坐标被替代；完整退休废弃通道、附着标牌、路口和旧机库造型。
- 金字塔十个实际楼面检查完整回型通道和两部主梯的层内互通；全地下通道按完整宽度检查，设备、屋顶与轨道分别定性。
- GeoFront 总部铁路从地表直接下降进唯一地下的金字塔站，再升回地表。地上与地下运输加速，同时保留原飞机、列车身份及实际支撑、占域和门禁联锁。
- 炮库作战和无关全局配置延后。

新增整备目的地参数及取消指令。机体血量、伤害和武器冷却等战斗平衡未调整。准备移动为 4 m/s，发射巡航设计值为 180 m/s，实际到达包含加速、闸门和机构准备。

本批修正了插入栓姿态更新阈值与更新后校验阈值不一致的问题，并恢复原 R50 吊机演出的检查范围：完整插入栓和驾驶员仍做连续碰撞检查，原非物理吊索绘制不再阻止送栓。撤回为避开新增检查而做的电机抬高 0.57 米及对应软管变化，保留原梁体、钢轨和吊机设计。

代码审查、构建结果和已有运行观察分别记录；本机无法顺利完成回放，实际操作、画面和性能仍待负责人验收，历史检查不转写为本批运行通过。
