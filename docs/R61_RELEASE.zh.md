## 和 R60 相比

**R60 小测试反馈的问题**
- 运输和发射时的抖动、发射时掉架，发射倒数后卡住。

- 处决时使徒穿到地下，地形上腿部扭曲，手腕扭曲。
- 两个腿部攻击更容易打中，部分动作补上了声音，拉米尔的攻击声音重做。
