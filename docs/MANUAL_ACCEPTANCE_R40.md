# R40 安装与人工验收

Minecraft 1.20.1 / Forge 47.4.10 / Java 17；通信协议 44。请使用同一批 R40 客户端和服务端。

本轮读完并对照了负责人提供的两份 Pro 文件。地图按实际方块、方块实体和三维通路检查；动作按骨架、支撑、接触、实际渲染分层处理。原作参考以 1995 TV 版为主。

## 安装

- **Client.zip**：直接拖入 PCL，创建新的 `Project SEELE R40` 独立实例。模组、模型、保存原进度的世界、材质、光影均已内置。PCL 只可能补齐缺失的 Minecraft / Forge 基础运行库。建议客户端内存 6–8 GB。
- **Server.zip**：解压服务端；把 World.zip 的内容解压到服务器的 `SEELE_R31_WORLD` 文件夹，确保其中直接有 `level.dat`。阅读 Minecraft EULA 后自行设置 `eula=true`，用 Java 17 运行 `Start-Server.bat` 或 `start-server.sh`。
- **World.zip**：独立世界包，解压后的根目录是世界内容。手动导入客户端时放入 `saves/SEELE_R31_WORLD`。
- **Shaders.zip / Textures.zip**：独立的光影、材质备份，合并到实例目录；Client.zip 已内置同一份资源。

旧 R39 实例和旧包保留。这个世界从原试玩存档合入静态差量，原玩家、机体、插入栓、任务和列车运行资料保留；未复制测试中的玩家或任务进度。

光影：选项 → 视频设置 → 光影包，选择包内 `ComplementaryUnbound_r5.3_SEELE_R39.zip`。该文件名沿用 R39 的室内补光版本。也可运行实例内 `Enable-Visuals.bat`，它只选择已内置的准确文件，不重新下载。光影首页的「SEELE 室内补光」仍可调节；总指挥席后的拉杆控制指挥室灯具。

本机开发入口是 `D:\eva\start_eva_test_r40.bat`，使用单独的 `SEELE_R40_WORLD` 副本；旧开发存档保留。可加 `--no-shaders` 临时关闭光影。

## 地图检查

本轮合入 **202,780 格有效方块修改**与明确的标牌 NBT 修改。原登记路线、新人行路线和接应平台路线合并为 **10,327 条已实走路径**。这表示登记范围的检查覆盖，不是对所有任意地点作零缺陷保证。

重点走一遍：

1. 地下都市入口站 → 大直梯：地下呼叫按钮、前厅灯具、入口大牌，再往返地面。不要通过管理员传送代替一次实际乘坐。
2. 地面人员入口：`226 81 306` 附近，刷卡后经下行梯和双向自动步道去原小直梯。入口已移到迎击区外，旧战时覆盖片段退役。
3. 金字塔：由站厅进总部，沿新牌子去最近电梯，再去指挥室、机库登机层和顶部接待层；检查各层的环廊和后部绕行。原大指挥室布局保留。
4. 机库站：站台南端接通原通道，检查围护、站台门、路线图和背面的提示。轨道之间不是候车区。
5. 军事基地：UN-00 接应平台约 `6466 77 -6048`，UN-01 约 `6278 77 -6048`。服务道路绕过 UN-00 平台，原两端仍相通；在装卸场停留时观察低位灯、边缘护栏和载台路线。
6. 地表城市：抽查楼门能否进入、入口净高、候车区边缘和城市外围的绿化过渡。

需要直接定位检查地点时，管理员可使用以下格式：

```mcfunction
/execute in projectseele:geofront run tp @s 226 81 310
```

## EVA 与使徒

五种 EVA 的普通攻击保留各自模型比例，重做了脚底支撑和膝关节约束；连击保留前一击的收势，再接下一击或移动。萨基尔使用相同的接触检查方法，正常战斗中保持主动攻击。

逐项观察：

- 空手左键连续两击，然后松开、前进、后退和转身。检查大腿/臀部是否侧翻、脚底是否突跳，手指是否跟着手掌。
- 靠近萨基尔交战，观察双方命中位置、受击移动和恢复。不要仅凭粒子或伤害数字判断动作。
- 在路缘、铁轨和小坡面上移动；分别做站立、蹲、趴、跳击和落地衔接。趴下时不能直接跳起。
- 初号机降至 **50 血**后进入静默、张口吼叫和暴走；剧情保护期间不会被击毁。与残血萨基尔满足条件时自然进入专属收尾。
- 新收尾中，萨基尔的卷曲组织与面具、核心、肘刺、手指分别处理，初号机有抵挡和落脚过程。最后确认爆炸只结算一次，角色控制能够恢复。

本轮没有调整基础血量、伤害和普通攻击时序。由于实际接触轨迹改变，命中次数和一次测试累计伤害可能不同。技术检查不代替动作审美、音色和操作手感的人工判断。

另外修复了城市状态定期刷新时同步读取远处未加载区块造成的长时间等待。此修复已在原卡顿位置和正式服务器包中检查；不代表任意硬件和区域都能保持相同帧率。

## 空运与回收

通过 UN 电话分别为两台 UN 机体安排投放和回收。它们使用核能；UN-01 保留飞行能力。检查正常机体与损毁机体各一次：

1. 等机库排液、舱门打开、载台驶出。起吊先脱离地面，再转为横向运输。
2. 倒地机体由当前姿态接载，回收前解除电力连接；不能把它先瞬间立起来。
3. 到达平台后有承重交接和一次落地声。UN 运输坐标按十秒间隔汇报。
4. UN 回到库外接应平台后，用电话选择「平台送回机库」。载台按机体实际姿态与库位尺寸安排朝向和位置，随后回到原机库身份。
5. 损毁机体回库后开始两分钟维修。检查原机体、原插入栓及机号没有被换成新的副本。

NERV 返航投放到原舱口后，会进入支撑架升起、开门、下降回库的交接流程。手动站上井顶平台时可使用普通回收。远处仍有遮挡或区块未准备好时会等待，不会穿过建筑。

管理员维护命令：

```mcfunction
/nerv transport status
/nerv transport force_recover
/seele military reset 00
/seele military reset 01
```

`reset` 是维护复位，日常优先使用电话运输与平台入库，便于检查完整机械过程。

## 第一幕

取得员工卡与 NERV 电话，联系冬月降下城市。电话联系美里，在「作战记录」中选择萨基尔、初号机以及亲自驾驶或真嗣出战。NPC 入栓后由指挥人员执行整备和发射；玩家驾驶中按 **O** 联系指挥室。

```mcfunction
/give @s projectseele:nerv_employee_card
/give @s projectseele:satellite_phone
/seele tv status
/seele tokyo3 retract
/seele tokyo3 status
```

亲自上机可以先 `/nerv route hangars`，前往初号机登机廊 `30 -394 -267` 附近，进入原插入栓。通过电话选择整备后发射；管理员分步检查可用：

```mcfunction
/seele eva prepare unit01
/seele eva status unit01
/seele eva launch unit01
```

等 `SILO_READY` 再执行发射。地面出舱后向中央沉降迎击区前进。首战支持其他机体与 NPC 途中支援，专属收尾仍使用初号机与萨基尔。

WASD 移动，Ctrl 奔跑，空格跳，Shift 蹲，Z 趴，左键普通攻击，右键重击，R 切武器，G 切力场，逗号键 `,` 抓取/投掷，V 脱离。近战先削弱力场，再攻击本体。详细选章、编队和回收步骤见同包《第一幕流程.md》。后续 TV 章节仍按原作顺序逐步制作，未把 Pro 报告中的原创支线当作已完成剧情。
