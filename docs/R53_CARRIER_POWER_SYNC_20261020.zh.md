# 转移电枪连接状态同步修正

2026-10-20，在当前玩家实际试玩存档的原初号机上复现并修正转移电枪反复接通、断开的显示问题。

## 根因与修改

服务端已经确认机体、转移架和电路连接，但客户端再次用两实体的位置距离判断连接。两实体的加载和插值不同步，快速转移时会短暂找不到架体，或出现超过阈值的距离误差，导致客户端错误断电。

保留服务端原有物理连接条件；客户端改为读取服务端同步的转移架供电位。普通 tick 和剧情提前返回分支均同步该状态。新增实体元数据后，网络协议从 71 升至 72，客户端和服务器须使用同批版本。

没有改变伤害、血量、速度、供电时长或实际插拔顺序。

在当前世界 `artifacts/r53_repair_20261015/client/saves/SEELE_R53_WORLD`，使用原初号机及原插入栓，通过正常登机、整备和地下出击流程进行两次服务端／客户端成对采样。期间正常空运回库并完成湿舱收尾，保存退出后安装；未恢复旧存档或重建机体。
