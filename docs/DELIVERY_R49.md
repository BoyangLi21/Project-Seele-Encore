## 人工验收顺序

1. 用同批 R49 两包启动并进入服务器，`/seele enter`，`/seele tp hanger`。
2. 三驾驶员休息室新门、两侧桥与半格上舱阶梯；正常登栓、插入、回收。真人操作不要只看 NPC 状态。
3. 电话选择地下出击；准备完成后走指定三门，回原接应平台再回收。随后地表出击，走离井口后按 V，原地检查空机与回收。
4. 昼天使任务选择 NPC 出击；二号机携剑。打死后检查 Boss 条立即撤下；不以调血代替这项。
5. 三机自然站姿、持刀连续攻击与收放；初号机 50 血静默 / 红眼暴走 / 收尾暗眼，处决全过程检查四肢、接触与重心。
6. 转移架升起、供电枪、电缆末端和输送；地面交接检查供电系统没有浮空。
7. 冬月上升 / 下降完整行程与中途播报；SEELE 会议层最高卡双面房门，灯按钮的日常 / 会议状态。
8. 保存退出再登录，确认原人物与机体身份、手中装备归还、地下接应与门灯状态。视觉、手感与远端服务器多人验证由用户验收。
