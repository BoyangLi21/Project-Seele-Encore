# R42 动作、墙面渲染与设施复核

2026-09-28。发布状态及文件校验值以同批 `RELEASE.json` 为准。本轮接续实际试玩的 `D:/eva/run/saves/SEELE_R41_WORLD`，LastPlayed 1790527495717，912 个源文件已冷备份。施工、战斗与机械测试分别使用独立副本。

## 根因与处理

**手掌基准错误。** 旧代码把腕部到中指根的向量当作掌心纵轴，但模型中的标记偏离掌心，算出的轴斜向横穿手掌。只换手指角度会让多个动作反复出错。现在以真实前臂到手腕的方向、四指根横轴及掌面法向建立五机共用基准；拇指单独朝食指对握。私有片段和运行时使用相同基准。

**动作相互覆盖。** 空中动作曾被站立警戒覆盖，循环飞行片段反复收放腿。现为空中单次压缩—展开，按离地、距地和触地状态驱动；起跳释放脚底锚点，空中不执行地面校正。攻击中切换蹲／趴会先保留退出姿态再混合，修掉直接取消造成的约 81 度上肢跳变。持枪空中路径不再遗漏手指，双人演出由完整片段统一控制骨架。

**收尾再次触发暴走。** 原收尾后仍为 50 血，立即满足再次觉醒条件。新增可保存和同步的暴走后休止状态，修复后解除；断电收尾保留演出最终姿势。红／黑眼材质覆盖真实眼部表面，停机不再只去掉光晕却留下亮色眼面。

**光影下墙面图案错显。** 旧图案在全局 `AFTER_TRANSLUCENT_BLOCKS` 阶段额外绘制，与光影深度／帧缓冲流程冲突。四幅图案改为有位置、支撑墙和包围盒的方块实体，通过正常深度测试绘制，背面剔除、墙体遮挡生效。两处指挥空间检查正面、背面及上层遮挡，另做光影关闭对照。

**检查工具漏洞。** 相机目标曾落进实心方块；移动失败后，旧工具可能把上一位置存成新视角。现在预检实心位置，校验实际相机坐标／维度，并保存截图收据。仅要求视野内结构完成加载，不等待身后被渲染器剔除的区段。另一次路径失败是新牌子挡住预设直线路径，现按摆放后的原生碰撞重算接近路线；失败记录保留。

## 战斗和演出

- 五机重建手部与连续肘部通道，普通两段拳保留接触时刻，重写准备、击出、随动及收回。
- 起跳初速 **6.2→5.3 格／tick**，重力增量 **0.32→0.42 格／tick²**；旧默认值读档迁移，自定义重力保留。实测普通跳跃 **25 tick（约 1.25 秒）**、最高约 **31.62 格**。伤害、血量、冷却未调整。
- 初号机保持 50 血觉醒及剧情保护，暴走红眼，击杀收尾后停机黑眼，修复或重新整备后恢复。
- 23 秒萨基尔片段保留既定流程，将原约 2.1 秒的跃起压缩为约 0.95 秒，紧凑翻转并立即承重。压制段降低躯干，左手保持对方表面接触，右手三次下击；镜头、接触和声音共用重定时。16.3–18.6 秒包覆缓存时段保留，避免错开附着。
- 低面数实心烟球改为柔边密度粒子，保留十字闪光与既有音轨。
