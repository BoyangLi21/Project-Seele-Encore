世界停在第【待定】批，代码是 main【待定】。在 R63r 的基础上：地图外改成开阔海、陆地边缘不再有条纹，地图本身又修了一大轮（第 456 批起），远景和小地图按新世界重新烘焙并包括外圈和 GeoFront 地下一层，内存占用进一步降低。**服务器和所有玩家必须一起换成 R64**，服主要整包替换（含世界）。

## 和 R63r 相比

**画面**
- 光影下，远处建筑里的机体、发射井里的门、机库门不再隔着远景建筑和山透出来（光影包加了远景深度测试，帧率不变）。

**地图外**
- 地图边界外生成开阔海：从已保存的海底 −90 自然加深到 −120，不再有沙滩浅台和直条纹；生成的海岸线和地图里的海岸自然接上。
- 北、西、南三边的陆地外缘不再有垂直于边界的条纹。

**地图修补**（第 456 批起，【待核对：按批次表补全】）
- 道路：东缘路、旧路面识别、高架下的路面并入路网、外圈道路换成 TrafficCraft。
- 第三新东京市空地补成整片城市街区，楼型、立面、行道树和街灯更丰富。
- 地形写实化：岩面分层、苔藓和植被、溪流两岸削坡、西边网格台阶、平原和海滩。
- 废墟收尾、隧道整修、浮空方块清理。

**远景和小地图**
- 远景按 R64 世界重新烘焙，包括外圈的海和山；R63 里沿用 R62 的 419 段核心远景也重建了。
- 小地图包括地图外圈，GeoFront 用完整洞穴层显示地下一层。

**EVA 和战斗**（【待核对：R64 是否默认开启新的移动模型】）
- 新的移动模型（初号机，脚踩实地的走法；斜坡、台阶、路缘）和跟随镜头。
- 手臂不再穿进墙里，站在边缘会退回一步；服务端按机体实际速度判断，不再误报"移动过快"。
- 萨基尔的刺拳更常抢在重击之前出手。

**性能**
- 远景数据改用 LZ4 压缩：7.2 GB 内存下不再出现完全垃圾回收，常驻内存约少 1.28 GB（远景数据库大约大 30%）。
- 关掉 SuperbWarfare 的载具加载区块：UN 基地不再常驻约 970 个区块（约 92 MB）。
- 动作和铁路数据去重，内存继续下降。
