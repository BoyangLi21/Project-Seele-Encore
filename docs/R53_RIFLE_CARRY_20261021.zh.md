# 新步枪枪托与胸甲穿插

用户指出持枪时双臂太低、太靠后，枪托进入胸甲。此前新模型的源面保留、双掌接触和地面净空检查没有包含胸甲，因此不能用之前的15帧通过否定本次反馈。

先在冻结的初号机原生提交网格上增加检测：原5帧均能检出枪与上下胸甲表面的三角边相交，计数454至962。`tools/audit_r53_rifle_chest_intersections.py` 保留此诊断；它只能报告表面相交，零计数还必须结合原生近景，不能独立替代体积和美术验收。

新枪的共同持枪坐标上移1.8格、前送3.8格，并向身体中线调整3.7格，使左臂也能自然够到前护木。双臂 IK、完整枪身、枪口和服务器弹道消费同一个坐标，不单独移动可见网格。左掌重新落在源模型较靠后的下护木上；第一版前送后蹲趴够不到的候选已拒收，没有拉长手臂。

旧模型资源继续使用原有持枪坐标。新源面的统一比例、9136三角面及2K贴图未改变。伤害、弹速、射程、冷却和弹药数值没有调整。
