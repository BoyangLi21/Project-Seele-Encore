## 车辆区块票与性能

- 工地持久 `chunks.dat` 清点：原版 Forced=0，Forge 的 51 条链接均位于 NERV，军事基地范围为零。军事舱仅活动开合/注排液态刷新自身票；UN 运输没有任务时不刷新任务票。该结果不涵盖瞬时短票。
- 实际安装 SBW 字节码确认，`VehicleEntity.baseTick` 对启用 KeepChunkLoaded 的车辆不论玩家/乘员/目标每 tick 刷新 `POST_TELEPORT`、半径 3、实体整数 ID 的短票。它们不进入持久 Forge 清单。
- `SbwParkingTicketsR44Mixin` 只抑制本项目原 UUID 受管车辆的自身短票刷新，不取消任何实体/AI/运动 tick，也不删除军备、修改防卫/供电或移除其他系统的票。
- 抑制前必须：同维受管 UUID+owned tag、着地无人、不乘载、不在火/水中、不受损、稳定位置/方向 100 tick、低位移；无发动机、开火输入、武器开火、AI 目标或拖挂；无战役和 UN/NERV 空运；玩家在视距缓冲外；256 格内无已加载使徒、敌对生物或已有目标的 Mob。null 或 native 状态读取异常一律保原票。
- 原短票自然过期。玩家接近、真实登乘、活动车辆和任何已识别作战恢复原处理；`projectseele.keepIdleVehicleTickets=true` 可回到原刷新行为。
- 取消计数不等于性能收益。主代理的 20 秒 JFR 已有服务器 612 样本，已识别的车辆运动/着地/支撑/目标视线/保票占约 34.6%；修后须同世界同位置抽样，并实际重新接近/登乘验证恢复。

功能参考采用 [JR 东日本站内无障碍路线](https://www.jreast.co.jp/estation/stations/900.html) 与 [国土交通省站内导视指南](https://www.mlit.go.jp/common/001255403.pdf)。本轮新增检修廊为原创工程解释，不宣称 TV 场景逐格复刻。
