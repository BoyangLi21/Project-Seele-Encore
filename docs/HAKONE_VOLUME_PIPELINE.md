# 已装地图的三维修复流程

2026-11-01 人工反馈揭示：只检查生成器自己的道路掩码，会漏掉旧设施、空间重叠和未登记残骸。地形高度图也无法表达铁路上方的空气、桥下道路和多层山地车站。本流程只用于离线修复，不加入运行时扫描或阻塞。

## 当前输入与范围

唯一进度来源是实际 `HOTFIX_20261025`。本轮冻结读取包含 87,753 个 FULL 区块；尚未完成的区块单独保存原生成状态。原始截图与外部评审材料位于 `F:/eva/delivery/R55_Map_Pipeline_Review_20261101.zip`。此包记录修复前问题，不是修复后的发行包。

这里的全图覆盖指所有已存 FULL 区块的地表工程高度带 Y=-128..319，不包含此高度带之外的体素。接触上界的非接地组件按 UNKNOWN 保留；本轮组件记录中没有接触该上界的候选。

统一地理坐标仍为 4 米对应 1 方块，不是 1:1。地形工程和保护既有设施引入的变形不能称作完全还原现实。

## 空间规则

1. 完整设备、建筑、楼层及交通身份来自当前存档和已有设施目录。
2. 建筑实体保护必须有有限 XYZ 范围；不能因为某列上方有设备，就冻结整列旧土。
3. 铁路车辆空间、已存道路各层的行走空间、机场露天空间分别记录为空气约束。空气本身也是需要保存的结果。
4. 地形场负责土石、坡面与边界。局部土柱或水柱不能自动成为水域保护依据；应结合已登记湖河空间。
5. 既有地下与发射通道保持原位。地表修复不降低原洞顶保护下限，不重置人员、机体、任务、交通和存档身份。

## 可复用步骤

- `capture_hakone_dimension_surface.py` 一次读取实际维度，分离 FULL 与 proto 区块，保存三维体素和设备位置。此处复用项目已有 Anvil/NBT 读取器。
- `scan_hakone_voxel_components.py` 从实际体素做六邻接连通，跨 region 合并边界。缺失邻区标记 UNKNOWN，不能冒称空气或可删除。之后只重算变化 region，重新合并共享边界。
- `verify_hakone_volume_repair.py` 根据当前原生铁路曲线读取列车全宽体积，直接检测机场实际铺装上方的土石；不读取修复器的编辑掩码。高架站的单层道砟与机场土盖板分开记录。
- `repair_hakone_volume_ownership.py` 按有限实体、通行空气、坡面顺序生成可逆候选。已写错的目标高度也要纳入坡度修正，不能只对照旧目标宣布通过。
- `prune_hakone_surface_delta.py` 去掉仅改土层颜色而无几何收益的变化，排除原地下保护范围。
- `finish_hakone_volume_repair.py` 清理明确废弃的独立自然物及铺装残骸，保留站棚、设备、有效道路、轨道和未知构件。悬空组件报告绝不是一张无条件删除清单。
- 对候选做实际体积剖面、必要的道路通行回归、设备 NBT 检查。每项报告必须注明覆盖范围和剩余分类，不能用区块数或中心线通过替代地图质量。
- 最后才更新当前存档差量、原生成配方、未来地形资源和变化区域远景。保留逐格旧状态前置条件和逆向补丁。只从隔离缓存服回填派生远景，绝不回填其世界、玩家或任务记录。

生成配方现在支持 `prepare_hakone_network_recipes.py --workers 4`。按 region 划分互不重叠的区块输出，工作进程只写自己负责的候选配方，主进程汇总设备检查与结果后发布最终报告。运行存档的安装仍是最后一个独立步骤。悬空扫描后续复用未变化 region 的连通记录，只重算变化区并重新合并跨区边界。

安装工具 `install_hakone_array_patch.py --workers 4` 也只并行准备互不重叠的 region 临时文件。主进程从头到尾持有冷世界锁，原方块前置条件仍逐项检查；全部准备完成后才串行备份和发布。改变区段读回或发布失败仍按原日志回滚，不允许工作进程直接发布到世界。

机场还发现目录边界比实际铺装短了数格，因此最终露天空域以存档中的实际跑道/停机坪铺装为依据。目录矩形用于定位，不应成为遗漏其边缘铺装的理由。

远景缓存导入前使用 `tools/java/IsolateCacheLodInputR55.java` 隔离缓存进程的输入。它只接受指定的 `cache-server/SEELE_R53_WORLD` 且要求没有玩家连接，在内存中停用 DH 的区块加载/变更事件适配器并清空其待转换队列，随后直接导入实际存档导出的列。原生数据提供器及父级合并继续工作。它不修改磁盘模组、实际游戏进程或世界方块，进程退出即消失。此步骤避免缓存服自身的运行模拟持续覆盖导入结果；等待已有转换和父级任务收敛后再做缺失区块缓存失效处理。

## 仍需要语义决定的项目

悬空站棚、轨道设备、桥梁和天然孤岛在纯连通图上可能相似。全图算法可以发现它们，但材质及连通性不能单独证明用途。道路断头也需要区分真实尽端、站前回车场和被截断的干道。应将这些对象与设施、端口、楼层和现役线路登记关联，保留待定列表；不得为了清空计数而删除功能构件。

本轮离线三维视图用于定位结构错误，不等于游戏光影、模型、街景或真人视觉验收。未获用户认可前不扩建湖岸、海港或 UN 基地。

收到用户提供的 Pro 独立评审后，已补通用安装冲突拒绝与类型保真的未知 NBT/未编辑 section 保护，详见 `R55_PRO_REVIEW_ADOPTION_20261101.zh.md`。实际维度下界为 -1344；本轮地表捕获下界 -128 不是维度下界。固定铁路包络检查不能替代同次原生全车型连续扫掠。统一 SceneIR、全高状态化读取和真实 Java 消费器回放仍是后续内部工程，不应描述成已完成。
