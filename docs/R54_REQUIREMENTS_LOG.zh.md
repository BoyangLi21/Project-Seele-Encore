PCL 命名依据：[官方 InstallPackCurseForge 源码](https://github.com/Meloong-Git/PCL/blob/main/Plain%20Craft%20Launcher%202/Modules/Minecraft/ModModpack.vb)。其读取 `manifest.json` 的 `name` 并校验文件夹名，非法或空名称会触发输入；R54 名称去掉了 Windows 不允许的冒号。已有同名实例仍需按 PCL 的重名处理流程解决。
