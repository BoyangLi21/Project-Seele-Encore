以下为以后有新地图改动时的调用方式，本次无需重复导出：

```powershell
python tools/export_patch_lod_r54.py F:/eva/artifacts/r53_repair_20261015/client/saves/HOTFIX_20261025 F:/eva/artifacts/r54_update_20261026/lod_refresh --patch-list F:/eva/artifacts/r54_update_20261026/lod-forward-patches.txt --deps .Codex/map-deps --workers 2
```

- 加 `--plan-only` 只读补丁坐标，列瓦片，不打开存档；数量随最终已装批次按并集更新。
