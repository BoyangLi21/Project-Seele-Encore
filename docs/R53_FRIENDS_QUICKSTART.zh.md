# Project SEELE R53 联机包 · 2026-10-25

## 朋友的客户端

1. 将 `Project_SEELE_Encore_R53_20261025_Client_PCL.zip` 拖入 PCL，安装整合包。使用 Java 17，建议分配 6–8 GB 内存。
2. 在多人游戏中添加服务器，**服务器名称填写 `SEELE`**，地址填写服主给出的地址。
3. 进入服务器即可游玩。PCL 包没有单人存档，已经包含当前模组、材质、光影和地表／GeoFront 离线远景缓存。

远景缓存按服务器列表名称 `SEELE` 预装；名称区分大小写。若改了显示名称，可在关闭游戏后，将本版本目录下 `Distant_Horizons_server_data/SEELE` 改成相同名称。只用于配套的本次服务端世界。独立 Offline_Render ZIP 是同一缓存的备用副本，PCL 用户无需重复安装。

## 按键

| 按键 | 功能 |
|---|---|
| `0`（主键盘） | 重载光影 |
| `-` | 开关光影 |
| `=` | 打开光影包选择 |
| `R` | EVA 切换武器／Superb Warfare 换弹，保留原玩法设置 |
| `O` | 指挥通信 |
| `G` | AT 力场 |
| `V` | 离开 EVA |

光影默认开启，选用当前 `SEELE_Local_Cavern_R53_Private_v1.zip`。画面设置为 60 FPS 上限、12 区块视距、6 区块模拟距离；可按自己的电脑调整。远景已有缓存，后台全世界生成关闭。

## 服主

解压 Server ZIP 到独立目录，使用 Java 17，运行 `Start-Server.bat`（Linux 使用 `start-server.sh`）。服务端包含本次正常保存的完整 `SEELE_R53_WORLD` 及原玩家、机体、任务进度。

服务端与客户端使用同一实际已安装的 R53 build 100 模组。第6次萨基尔行动已自动归档；零号机已有回收订单会随游戏继续运行。屋岛作战留到下一轮。

缓存只影响远处显示，不包含客户端单人存档，也不使近处方块不可破坏。当前随附的是已生成区域的三维远景，不是宣传图的离线路径追踪画质。
