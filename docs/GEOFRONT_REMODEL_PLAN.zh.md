# GeoFront 改造计划（验收后的下一轮）

负责人 2026-11-08 决定：保留现有设施，按下面这个模型改造 GeoFront 地下空间。排在本轮地图验收之后，和 UN 迁移放在同一轮做。本轮不动工。

## 负责人要的效果

- **EVA 发射通道：** 只有它在地下能看到，从底部直冲到顶。
- **人员大直梯：** 像模型里一样，沿 GeoFront 边缘螺旋上升，到原来的出口。
- **地下铁路：** 同样沿边缘螺旋，通到地面一座车站。
- **速度：** 电梯和列车都要极快，负责人原话“超级超级超级超级快”。
- **地下天然湖：** 按模型做。
- **城市沉降：** 天花板倒挂的沉降城市按模型的样子做。负责人认为这一项和模型差得最多。

## 开工前要定的

1. **比例和对位：** 模型穹顶直径对应我们 GeoFront 的多大，金字塔和湖的位置怎样与现有设施对齐。
2. **“保留原设施”的边界：** 哪些现有建筑、通道和运营路线原样不动，哪些可以为螺旋线让位。
3. **速度：** 电梯和列车具体多快。MTR 列车和升降机能跑到的上限要先实测；超出时要不要自己写运输逻辑。
4. **沉降城市：** 只做成倒挂的静态楼群，还是要能整体升降，和地面城市联动。
5. **范围：** 和 UN 迁移的先后，以及是否需要单独的验收。
