# R53 两站空间复核与总部站残留清理

本批沿用实际试玩存档 `artifacts/r53_repair_20261015/client/saves/SEELE_R53_WORLD`，
分别冻结旧试验机库站区和总部站区。全部方块实测经 `query_blocks.py`；
人员楼面、楼梯、玻璃围护顶面、站台边与列车净空分别判定。

## 旧试验机库站

冻结范围 X80..200、Y−480..−425、Z−90..30。检查3,419个有效导航点、6,292次身体扫掠，
16处栏杆分隔均没有错误的穿栏导航边。5个关闭层门与60个楼梯接口单列，未据此删除节点。
初筛396个几何边缘候选中，7个能从站台绕到的候选位于东端列车净空和半砖路基旁；
五个原生机位确认列车进出站，不按悬空人行缺口填补。实际有效导航楼面无新跌落候选。
屋面不视作人行面，12块带模型吊链的屏幕保留。本站本次没有新增方块或导航修改。

## 总部站修正

冻结范围 X−32..95、Y−576..−529、Z464..559，补齐上一批金字塔扫描未覆盖的南端。

- 清除三段四格长、完全孤立的旧混凝土残留：X−5..−2、11..14、43..46，Y−551、Z506，
  共12格。原生近景确认与承重梁断开；不改仍连接的梁、屋面或灯具。
- 停用被误登记为人行楼面的60个玻璃围护顶面节点：X39..53、脚位Y−556、
  Z475/505/507/537。用途依据为原R20车站外围墙与R52整体下移93格的原结构。
  玻璃墙本身全部保留。同步移除136条相关有向步行边，重算目的地与最近电梯指引。
- 四段楼梯共120格踏步保持原状；上下落脚、净空与首级检查无新增问题。
  6个关闭闸机保留动态通行语义。最后剩余的1处一格高差位于东端铁路隧道口，
  原生图确认属于列车路基，不补成站台墙。

修前完整有效节点检查为3,860点、75个跌落方向候选；移除墙顶错误导航后为3,800点、
6,889次身体扫掠，74个墙顶候选消失，76处围护分隔均没有穿栏导航边。
这不是全域交通运行或所有设备状态验收。
