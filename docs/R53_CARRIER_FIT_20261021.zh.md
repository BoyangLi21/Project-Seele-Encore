# R53 新转移架与后移踏板

本批接入用户提供的转移架，并按最新反馈把斜踏板移到脚跟后方。踏板保留原模型角度；没有继续把它当作前方护板旋转。背部导轨连接另列后续，不能据本记录宣布整套转移／发射系统完成。

## 源模型与调整

- 两个 `industrial machinery 3d model` 压缩包分别提供 FBX 和 OBJ，核对为相同的8727三角面；本批用FBX，保留全部面、原UV、分裂法线和4096×4096底色。
- FBX SHA-256：`a51093f2bcf82d864d0ad1517a3a9a815fa0729dab87c08cdc12ff79e34c8941`。原JPG：`f283dc0f0ae44d9198650a4046870c41992c92575b7b2364e6bcf97fee332972`。
- 导入器 `tools/import_carrier_mk2_r53.py` 根据已核对源文件分出137个连通部件。统一尺度57；局部Y偏移−4.0078125。轴变换反转手性，因此一并反转三角面绕序与UV／法线次序。
- 踏板局部位移 `(0, −0.75, +10)`，其中+Z指向机体后方。保留原斜面；下部横撑整体等比0.65以让出脚跟，源面均保留。四个夹爪作刚性横向适配，增加96面伸缩支架。
- 初版仅竖直升起时仍扫过小腿，已拒收。现按两个仿射阶段处理：先在机体后侧升起，再前移合拢。足下底板及踏板不随背架升起。伸缩支架随对应活动组件后收，避免升起时脱开。
- `CarrierAssemblyR53` 同时向渲染、路线扫掠与门净空提供源面和动作变换。选择清单校验网格和贴图哈希，未安装私有模型时使用原有模型。原三条路线、原角色／机体／转移架身份与原目录不变。
