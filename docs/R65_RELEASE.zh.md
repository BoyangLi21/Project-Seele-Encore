# Project SEELE Encore R65 更新说明（发布候选草稿）

从 R63r 升级时，请让服务端和所有玩家使用同一版客户端。R65 使用协议 84（R64 没有单独发布，内容都并进了 R65）。正式包日期、默认启用的动作选项及最终收录的候选功能，待负责人验收后确认。


## R65 新增

- 莉莉丝层的天堂之门可以开合：点门框、门扇或门牌开关，门前有人时不会合拢。
- 新配置默认使用新的移动方式（脚踩实地）和新的战斗节奏；旧的仍可在设置里换回。
- 修好几处动作：匍匐时身体贴地、起身撑地时手不再插进地里、UN-00 倒地后更快起身、零号机踢腿起手不再跳帧。
- LCL 长廊那一层的电梯按钮显示中文层名「LCL同步实验层」。
- 城市升降和自动存盘时的卡顿进一步减少；箱根出口弹射时的偶发卡帧减少。

## 试玩后的修正（2026-11-24 包）

- **远景和地图外圈**：外圈地形已经存进包里的世界，服务器不再在外圈现场生成地形。远端服务器上远景缺块、外圈出现一大片错误方块的问题随之解决。两边的 Distant Horizons 只读已有数据。
- **城市虚影**：包里的世界改为城市升起的状态，和远景一致，市区不再出现楼的虚影。
- **GeoFront 穹顶**：在地下空洞里，穹顶、倒挂城市、湖和金字塔的远处轮廓由真实方块烘出的简化模型显示，不再残缺发黑；开不开光影都有效。第一次进入空洞会短暂卡一下。可以在 `config/projectseele-client.toml` 的 `[geofront_far_view]` 里关闭（`enabled`）或调亮度（`light`）。
- **地下小地图**：GeoFront 地下一层的小地图按真实方块重画，分层图集的地面层也重画了。
- **螺旋线**：地面员工出口站扩建，有 MTR 售票机和刷卡闸机，两个始发站显示下一班车的倒计时。每位玩家第一次进服会拿到一张 NERV 员工卡，用来刷闸机。
- **电梯和列车**：服务器上乘电梯时不再被拉回或卡出轿厢，横移时轿厢不再前后跳，同乘的其他玩家站在地板上不抖。乘螺旋线列车（700 km/h）时也不再被服务器拉回到车后。
- **天堂之门**：去掉了门旁的浮空方块；开关门时有摇柄动作、闸门声和提示文字，走近时会提示怎么开。
- **机库和屋岛**：检修笼停着时，插入栓挂在插入吊机上。屋岛炮台的零号机电源点改到左侧，有自己的电塔。
- **动作**：萨基尔抱住初号机时，初号机的胳膊不再扭曲；出拳向前打出，腰和腿跟着发力；硬踹时双手不再缩成球。
- **声音**：初号机的脚步声改成机械的落脚声，不再像水声；防空警报按所在区域带不同的回响，机库和地表各不相同，整体音量调低；攻击时的关节摩擦声去掉了。
- **其他**：客户端包默认给 6 GB 内存。修好专用服务器在螺旋线车站闸机附近可能卡死一分钟的问题。

## 箱根与第三新东京市

山路接回了原来的车道、住宅门和车站入口。四段短坡重新选线，连同原路接缝测量，最陡的一段约为 7%。散落在草地上的旧沥青碎片也已处理。沿地图边界走，原地图的山坡逐渐接入外侧生成的地形；海底从近岸向外海逐渐变深。少数高崖仍然保留。

仙石原一带用夏季的绿色高草表现芒草原，草丛间有蕨、小花和少量孤树。城内修整了 Comfort 17、团地、旧步枪站旁的坑和 LCL 长廊电梯口。升降楼收起时，沿街设施随城区收起；城市升回地面后，原路口的设施回到街面。城区的 22、28、40、45 号备用武器楼各有一支托盘步枪，供 EVA 取用。

## 从机库出击

站在机库边缘可以看见整片连续的 LCL 液面。乘弹射架出击时，通道压暗，近处先显出灯带和横肋，闸门在机体接近时开启。地下都市、市区和箱根三个出口的九条线路采用同一套墙面样式。

插入栓的弹出键会先要求确认。驾驶舱里的同步率随剧情、受击和机体状态变化；初号机首战的基准为 41.3%，屋岛为 52%。暴走开始后，读数一路升到 400%，再超过仪表量程。此时请求弹出会看到「弹出信号被拒绝」，停机恢复后才可以重新弹出。英文驾驶舱的相关仪表和作战通信也有对应译文。

## EVA 战斗和屋岛作战

初号机的轻攻击是左右拳，闪避后和跑动中按轻键也一样。抓住使徒后可以按住捶击，硬踹有自己的动作。斜着撞墙时脚部会避开墙角，爬陡坡时前掌承重、脚跟跟着坡面放下。抓后捶击的伤害和既有命中时刻沿用原设定。

屋岛作战时，零号机在指定位置持盾待命。电力转给固定炮时，从街面、炮座或瞄准镜都能看到城区分片熄灯，远处的灯光与街面同步。山体会遮住背后的拉米尔。任务中仍需完成两次射击。

## 终端教条与运行表现

通过天堂之门进入莉莉丝层，可以看见加深的 LCL 池、调整过比例的莉莉丝和承住双手的十字架横梁。场景中的枪可以在有枪和无枪两种状态间切换。

城市升降期间分批处理区块存档，街道设施也会提前加载。新增的地图外圈远景缓存采用 LZ4，以缩短加载时间。客户端包带上了分层图集资源包，默认启用，小地图和大地图能分层显示 GeoFront 地下各层。核心城区沿用已有缓存，并重烘本次改动涉及的地段。服务端关闭了 SuperbWarfare 载具常驻区块的选项。新远景与小地图以本版世界为基础，实际缓存范围和最终包大小以发布回执为准。
