# R48 人工验收版本

本版基于用户确认的 R47 服务器包内存档。完整玩家、实体、插入栓、任务、库存及交通数据保留；没有宣称已合并云端服务器之后产生的进度。完整动作、画面、听感、服务器操作与多人体验由用户验收。

## 安装

- 服务端：`Project_SEELE_Encore_R48_20261005_Server.zip`，包含 `SEELE_R48_WORLD`、模组与运行配置。Java 17，Forge 1.20.1 / 47.4.10；启动脚本上限 20G。阅读并同意 Minecraft EULA 后自行修改 `eula.txt`。
- 客户端：`Project_SEELE_Encore_R48_20261005_Client_PCL.zip`，直接拖入 PCL，创建独立 R48 实例。21 个客户端模组内置，整合包 manifest 的远程模组列表为空。基础 Minecraft / Forge 文件由 PCL 按需补齐。
- 两端网络协议为 56，使用同批客户端和服务端。材质、光影原包及本地光影初始化入口都在客户端内。
- 服务器显示 `EVANGELION:Encore R48测试版`，使用 64×64 NERV 图标和彩色简介。
- 个人模型与世界包放在本机交付目录；公开仓库只包含代码、可公开资源和制作工具。
