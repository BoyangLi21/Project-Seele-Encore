# Project SEELE: Encore — R45 人工验收版

本轮按负责人的最新安排收尾：美术、动作观感、战斗与驾驶整体体验、服务器表现由负责人验收。这里只把实际实现、检查和仍未启用的内容分开记录，不声称“完美”或“3A 已完成”。

Minecraft 1.20.1，Forge 47.4.10，Java 17，网络协议 **53**。不要混用旧协议49/52的客户端与服务端。

## 安装包

批次前缀为 `Project_SEELE_Encore_R45_20261004_CANDIDATE_`。以最终交付消息中的实际 ZIP 和清单为准。

| 后缀 | 内容 |
|---|---|
| `Client.zip` | 完整客户端、核心模型、配套世界、额外材质和光影；光影默认关闭 |
| `Client_Plain.zip` | 相同玩法、核心高精度模型和世界；无额外材质、光影和 Oculus |
| `Server.zip` | Java17/Forge 服务端、同批 mod、运行配置和世界 |
| `World.zip` | 独立存档，目录名 `SEELE_R45_WORLD` |
| `Textures.zip` | 本批 Terrain128 / NERV256 材质与来源说明 |
| `Shaders.zip` | 固定版本光影及本地设置入口 |

客户端 ZIP 拖入 PCL，新建独立实例。先用 Plain 或关闭光影检查操作，再对照完整客户端。不要把新包直接覆盖正在玩的旧实例；两个客户端的核心功能和模组应相同。

服务端在新目录解压。确认 `server.properties` 的 `level-name=SEELE_R45_WORLD`，世界目录内直接有 `level.dat`。阅读 Minecraft EULA 后自行设置 `eula=true`，用包内服务器启动脚本。JVM 参数为 `-Xms2G -Xmx20G`，20G 是上限。服务器实测和多人体验由负责人完成，本轮没有伪造20G服务器验收记录。

## 本轮实际整理

### 手、动作和武器

- 保留原高精度机体表面，三机采用各自的手部骨架。没有把原粒子刀换成简化新刀。
- 空手静止、走路和跑步的手腕按真实掌面坐标对齐前臂。旧静止帧里手掌纵向与前臂偏转约45–52°，造成向前兜手；新空手基础姿态保留小幅放松弯曲，武器和攻击在其后独立控制。
- 普通站姿轻击采用 Mesh2Motion 的完整 Jab / Cross，两段循环；重击包含完整收势。素材主要为作者关键帧动画，不能统称真人动捕。
- 二号机新增独立长剑和三段剑击、重剑击、持剑姿态。剑跟随手掌，实际刃面参与接触；原短刀保留。剑的新抽出/收回动作尚未制作完成，不把持剑待机冒充抽收动作。
- 大幅动作位移改为分段通过真实碰撞，避免超过旧6格阈值便丢掉整帧位移，造成腿在动而机体没有跟上。
- 三机增加方向闪避和前滚。退出动作前同步最终位置并清理旧插值，避免把控制权还给驾驶员时产生迟到的位置校正。没有额外添加无敌帧。
- 枪械转向、趴姿抬头、切换后错误回到旧姿态等已有针对性代码修正；实际手感和仍能复现的问题请在同批包中检查。
- 暴走候选引入 Walk_Large、Zombie 低姿态/吼叫及左右抓击。50血触发与已约定的剧情保护保持。普通走跑没有整套替换成 Zombie。
- 主动弹出、断电和被击倒仍是不同状态；主动退出和断电应保存当时姿态，不能一律播放死亡。新收集的死亡/起身素材尚未全部接入当前物理状态机。

### 地图、材料和设备

- 最新地图副本保留完整玩家、实体、任务、交通及原有归档数据；没有用动作测试世界覆盖正式进度。
- 车站已合入一批完整站面材料与有支撑的线路图；最后合入十处双轨站岛式通道的20块双面图牌。
- 七部直梯的顶棚，以及三部人员直梯的内饰，已换用专用材料。形状仍是完整立方体，按钮、门洞和原设备数据保留。
- 指挥设施人员门采用新的压门外观。真实右键事件现在接入既有开门处理；过去检查直接调用处理函数，漏掉了游戏事件未接线的问题。
- 城市升降恢复可用状态，依据已有同一96组结构的实际运行和冷回读继承；不是本轮正式服务器速度证明。尚未取得发布环境证明的新形状并集优化保持关闭，保留安全实现。
- 模型、动作、物理与恢复等资源按游戏实例目录加载；模型核心资产内嵌，避免 Plain 客户端丢模型，也避免启动器工作目录不同而静默退回旧动作。

## 驾驶操作

| 输入 | 用途 |
|---|---|
| WASD / Ctrl | 移动 / 奔跑 |
| Space / Shift / Z | 跳跃 / 蹲姿 / 趴下和起身 |
| 左键 / 右键 | 普通攻击或步枪 / 重击；阳电子炮右键蓄能 |
| B / R / G | 踢击 / 切换武器 / AT 力场 |
| 方向键+C | 空手或短刀站姿方向闪避 |
| 奔跑+方向键+C | 朝所选方向翻滚 |
| O / V | 驾驶通信 / 弹出插入栓 |

在机库转运、发射等机械阶段，C 仍先执行取消发射，不能在轨道上翻滚。零号机蹲下不会自动举盾。完整盾装备未启用。翻滚源位移按巨人比例转换，距离较长，请在城市中央开阔区体验后反馈。

## 建议先检查这些

1. 不开启任务，上机后观察是否保持待命；取消任务后再上机，也不应自动准备/发射。
2. 三机分别静止、行走、奔跑和转向，重点看手是否自然垂落，腕部是否折弯，脚步与身体是否一致。
3. 连续左右键、停一下再接招、边移动边攻击；看是否出现腿部拉长、动作消失或停不下来。
4. 前后左右闪避、奔跑翻滚，结束后松键站定，再正常移动。也试一次近墙受阻；动作不得让实体穿墙。
5. 站姿、蹲姿、趴姿依次切枪、开枪、转头、起身、切回空手。尤其记录旧趴姿是否再次冒出来。
6. 二号机切到独立长剑，逐段轻击和重击；确认手握、剑是否重复显示、剑刃接触与实际伤害。
7. 进入/离开插入栓、断电、受击倒地后恢复。记录手脚、头颈有无脱离及位置跳变。
8. 真实按按钮走过人员门；直梯从门外呼叫、进梯、到站再走出。新的外观和材料请你直接判断。
9. 从站口到闸机、站台、列车，再走向附近建筑；检查新图牌方向和位置。纸面路线检查不等于真实乘降已经全数通过。
10. 最后开光影，比较手、武器、AT 力场、驾驶第一人称、阴影和地下照明；再在服务器重复核心流程。

## 快速定位

需要作弊权限或服务器 OP。

```mcfunction
/seele enter
/seele tp
/seele tp hanger
/seele tp command
/seele tp observation
/seele tp hanger_station
/seele tp station
/seele tp tokyo3
/seele tp airport
/seele tp port
```

`/seele tp` 会列出当前已注册的地点。不要用旧的地图生成命令重建已经存在的世界。

## 第一幕的最短流程

```mcfunction
/give @s projectseele:nerv_employee_card
/give @s projectseele:satellite_phone
/seele tv status
```

手持电话右键通信，驾驶中按 O。先联系冬月收纳城市，或执行 `/seele tokyo3 retract`，用 `/seele tokyo3 status` 查看状态。等待中央区域准备好。

通过美里的作战记录选择萨基尔、初号机和亲自驾驶。也可使用 `/seele tv select sachiel` 与 `/seele tv begin` 选择并开始本章；驾驶员安排仍通过通信选项处理。

进入机库原插入栓。若已经安排了 NPC，先让其下机待命。正常有任务流程应由指挥人员推进；人工分步检查可以用：

```mcfunction
/seele eva prepare unit01
/seele eva status unit01
```

到 `SILO_READY` 后：

```mcfunction
/seele eva launch unit01
```

抵达地面后等待门和支撑完成交接，在中央可升降区域交战。先处理使徒 AT 力场，再攻击本体。初号机低血暴走和首战收尾属于专属组合；动画观感、镜头与声效由你验收。

结束后查询 `/seele tv status`，回井口停稳，电话请求回收或执行 `/seele eva recover unit01`。用 `/seele tv cancel` 取消尚未结束的作战；不要反复 reset 掩盖最先发生的异常。
