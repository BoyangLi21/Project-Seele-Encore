## 本次只交两个包

按你的最新决定，服务器全新部署，只交 **Server** 和 **Client**。

### 服务器

1. 解压Server ZIP到新的服务器目录。包内已有Forge **1.20.1 / 47.4.10**运行库、全部服务端模组、配置及 `SEELE_R46_WORLD`，无需另外再装一套Forge。
2. 使用Java **17**。Windows运行 `Start-Server.bat`；Linux运行 `bash start-server.sh`。
3. 如同意Minecraft EULA，将 `eula.txt` 中的 `eula=false` 改为 `eula=true` 后启动。
4. 启动参数为最大堆内存 `-Xmx20G`。`server.properties`已指向配套的R46世界。不要再覆盖旧存档或旧模组文件。
5. 服务端出现正常的 `Done` 后，用同批客户端连接。管理员权限仍由你在服务器上设置。
