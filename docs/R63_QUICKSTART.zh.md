# R63 联机说明

客户端和服务端请使用同一批 R63 包，不要和 R62 或更早的包混用。

## 玩家

1. 把 `Project_SEELE_Encore_R63_<日期>_Client_PCL.zip` 拖入 PCL，默认实例名为 `EVANGELION_Encore_R63`。
2. 使用 Java 17，在本版本设置中分配 8 GB 内存。Minecraft 1.20.1、Forge 47.4.10 由启动器按清单安装。
3. 进入多人游戏，列表里已经有名为 `SEELE` 的服务器，直接加入。这个名称用来匹配预装的远景，不要改。

包里已经带好小地图和预渲染的远景，这一版的远景包含新的地图外圈，比 R62 大。进服后小地图立刻是完整的；远景大约一到两分钟加载完。

小地图按服务器地址匹配。服主换了地址的话，预装的小地图不会生效，要用新地址重新打包。

客户端包不含单人存档、启动器和 Java。`PCL/Setup.ini` 只有版本隔离和 JIT 启动参数，不含账号信息。`jit-recovery-r54.json` 不要删。

光影下远处的小实体不投影，可以在 `config/projectseele-client.toml` 的 `[shadows]` 里调整距离，填 0 恢复全部投影。

## 服主

把 Server ZIP 解压到单独的目录，Windows 运行 `Start-Server.bat`，Linux 运行 `start-server.sh`。使用 Java 17。内存沿用上一包的 2 GB 初始、20 GB 最大，可以在 `user_jvm_args.txt` 里按机器调整。

世界在 `SEELE_R53_WORLD`，这是历史目录名，产品版本是 R63。R63 带的是新世界：如果已经用 R62 开过服，换上新世界会丢掉玩家在旧世界里的进度。不要把旧包的世界或远景数据库覆盖回来：包里的远景数据库做过处理，能避免客户端重复下载。

**只能用 R63 包里的模组打开这个世界。** 地图外圈由新模组生成，旧模组打开后会在外圈长回旧地形，而且写进存档就去不掉。

## 道路 mod

地图的道路用 TrafficCraft 的方块，铁路和车站用 MTR 的方块，两个包里都已经带了。把世界搬进自己装的实例时，先放好 `trafficcraft-forge-1.20.1-1.1.3.jar` 和 `MTR-forge-4.0.5+1.20.1.jar` 再打开存档。遇到缺方块的提示一律退出，不要点继续，否则路面和铁轨会变成空气。

## 指令

游戏内指令都在 `/seele` 下，输入 `/seele` 后按 Tab 查看。旧的 `/nerv`、`/un` 等写法已经删除。城市升降被打断、卡在半途时，管理员用 `/seele city recover`。

## 常用键

`R` 切换 EVA 武器，`O` 指挥通信，`G` AT 力场，`V` 离开 EVA；主键盘 `0` 重载光影、`-` 开关光影、`=` 选择光影。屋岛炮位按住右键蓄力、松开发射，Shift＋右键退出炮位。
