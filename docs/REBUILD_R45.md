# R45 制作与验收

2026-10-02 继续 Encore 项目的交付重构，R44 阶段版已被实际试玩再次指出动作和环境质量不足。

底本为本机安装的 R44 配套世界，源码起点 `7a44b673eada0895eccb1c585655a5df510070f8`，协议49。最近客户端连接了远端服务器；按照此前本地底本授权施工，服务器后续运行进度不能由本地世界推定。

## 当前用户指令

1. 优先补齐三个机位的完整新桥／人员工作平台、实际进入、承重和机械运行状态。
2. 修复城市升降极慢的首因，核对 TV 中心升降方式；服务器最大堆20G、初始堆保留较小值。
3. Root 亲自修复三台 NERV 机的连续左键脚锁、跑步、转头横移、动态手指、眼睛停机状态和整体动作／模型质量。模型与动作不得交给子代理。
4. UN 两机模型与动作暂停；生成交付存档前把 UN 机库及机体置于初始待命状态。
5. 最高会议室司令座椅后方新增精细基座与可阅读的死海文书：第一页生命之树，后续依据 TV／《EVA2》机密情报及已核验百科编写，区分来源与原创内容。
6. 更换设施播报与警报声音；LCL 继承当前光影包原水渲染，调整橙红色，逐视角检查。
7. 完成学校及泳池；按原作与真实箱根站资料重制车站；整体地形对照箱根山地、仙石原、芦之湖、相模湾及原作。
8. 继续关闭 R44 的完整未完成清单，以接近发布的实际游戏表现为标准；源文件存在、编译、检查计数不能替代视觉与玩法质量。

## 工作边界

玩家、任务、机体、插入栓、NPC和交通身份／完整NBT继续保护；原始底本冻结，单一施工副本、单一世界写入者。新规划须覆盖实际用途、设备运动包络和既有对外连接，退役组件及会重新生成错误的维护代码一起修。

本轮暂仅城市升降性能与服务端内存由并行代理处理。模型、动作、机库机械、新桥与文书的几何和实际画面由root处理。UN暂停指令优先于旧“五机一起制作”计划。

## 当前进度

初始冻结、原作与真实地理研究、首因排查进行中。没有新的功能／美术通过记录；后续按实际修改、实测、视觉自审、用户认可和未验证分别更新。
