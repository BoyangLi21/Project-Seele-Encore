# R53 电梯门：轿厢对齐与透明双开门

人员电梯原来按独立门实体的位置包绘制，轿厢则使用 Moving Elevators 的连续位置及水平转移时钟。两个来源的时间不同，运行时会脱离。现在轿门同步原生组及局部安装点，最终绘制和裁剪边界都取同一个原生轿厢样本。新实体元数据要求网络协议 72→73。

开门时，整片滑出的玻璃曾与固定侧玻璃重合。现在保持原叶片位移、材质及 UV，裁去进入侧边收纳区的部分。地表大电梯 X=-360/Z=750、停层 -466/81 改为透明双开层门与轿门；关闭等待完成后再允许原生电梯启动。

## 已验证范围

- 冻结的人员电梯旧版记录有 1,726 个移动样本，门与轿厢垂直偏差中位数约 0.85 格、P95 约 8.35 格、最大 16.73 格。
- 修正后人员电梯完成 -1014↔-502 往返，包括 -566 的水平转移。1,958 个有效样本按同一原生时钟比较，偏差为 0。旧比较公式的浮点求值顺序曾触发水平转移边界，已纠正，不采用那组伪大误差。
- 大电梯完成原生 -466↔81 往返；带可见门的验证共 1,854 个样本，绘制中心与轿厢安装点偏差为 0。补上玻璃收纳裁剪后的复验 1,846 个样本，除初次生成外均有门，偏差为 0。
- 已查看实际客户端的人员门与大电梯开门、关闭截图。内部朝门相机的一组辅助图朝向错误，不作为视觉证据。
- 完整 `gradlew build --offline --max-workers=2 --console=plain` 通过。协议 73 安装后原世界正常启动并载入玩家。
