本轮升级范围是三座湿舱、拘束机构、后颈插栓、人员层、吊机、载台、转移线和发射井的一套空间。已经修复的楼面、全部设备净空及原机体/插入栓身份保留。服务走廊饰面、皮肤换色、shader 修复和局部截图都不能代替整机库验收。

## 当前候选和未关闭项

原 `hangar_tv_calibration/semantic_frame.json` 的 legacy80m壳顶假定已由实际 roof−355 修订，当前以 `hangar_tv_calibration_v2/semantic_frame.json` 为准；保三原机/栓、29 个湿舱接口完整 NBT、12 个整面实测和同一121姿态包络。该目录的 `hangar_semantics_3d.html` 同步真实屋面、双轨、外置吊柱及共用转移厅剖面，是可旋转离线语义检查图，不是 Minecraft 照片。

`tv_hangar_envelope_v3` 是 107,081 格、136 chunks、66 BE/12 stored entities 完整保留的静态皮肤候选。它使用实际湿舱屋面−355和一个实际共享转移大厅（外墙X−35/95、roof=floor(guide_y)+86），不把三条载台槽当成三个独立房间。所有变更均保持相同原生完整立方体碰撞，无 air/fluid 填方。V1/V2 均未施且已撤回，禁止使用。

`hangar_structure_v3` 的1,389格与 `working_edges_v1` 的294格由 root 精确施工：吊机双轨顶面−373与新车轮 localY0一致，外置吊挂到真实屋面，避免吊柱位于轮轨行进线上。源 producer 三种更新路径统一为原EVA轴X=cx+.5，旧的0.5m错位与声明高轨10m错位都修正；当前原高轨owner EDGE已无剩余，不拆该棱柱里的其他玻璃/结构/灯。侧工作层旧template只铺offset18/19却在17画栏，本轮补17真实承重lip/下托并保两列净空，48条从原真实层站到每条双端/双列的来回病例仍需native执行。

后门实测每舱有 2,343 个 barrier，属于运输门碰撞面，不能认成缺墙。单一 front 平面的 air/void_air 也不等于压力边界缺失；需配对原窗口和错层围护。设备坑不靠颜色或照片推断填平。
