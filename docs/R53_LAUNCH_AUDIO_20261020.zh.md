# 发射轨道音色修订（2026-10-20）

用户反馈旧电流与摩擦声不好听。本次重合成原有两个事件的音频，不改变发射时序、火花位置、伤害或速度。所有声音均为固定随机种子的原创数学合成，没有采样官方音轨。

## 改动

- 起射电流由1.85秒改为2.1秒：短接触冲击、低频电磁脉冲、短电弧和逐渐衰减的低通反射。减少持续高频噪声，保留起射冲击的峰值层次。
- 轨道摩擦由0.31秒改为0.74秒：接触声以中低频滚动、摩擦和少量瞬态为主。按原有12tick间隔自然衔接，最高普通播放音高1.1时仍有短重叠。
- 摩擦目标峰值由0.82降至0.34；起射仍为0.82。48 kHz单声道、原事件ID、字幕和192/128格衰减配置保持。
- 生成器支持单独候选目录；打包回读工具同时适用于首次添加和修改已有事件，不再假设基准一定缺少这两个声音。
