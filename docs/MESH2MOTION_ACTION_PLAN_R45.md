# Mesh2Motion 动作清单与接入安排（R45）

本清单逐项来自下载后的三个实际 GLB，共 178 个动画条目。目录可用不等于已适配、已验证或用户认可。

来源：https://mesh2motion.org/ ；https://github.com/Mesh2Motion/mesh2motion-assets/tree/main/rigs/human 。素材 CC0，应用代码 MIT。源文件下载与 Git blob/SHA-256 见 artifacts/rebuild_r45/motion/mesh2motion_research_v190/download_receipt.json。

三包均有 66 根同名关节，但基础包与扩展包的绑定局部变换存在差异，必须分别使用各自绑定姿势校准。扩展包 Fighting Idle / Left Jab / Right Jab 的边界肩部最大差异约 72–75 度，不能直接拼接；需要实做过渡。作者称主要动画为手工关键帧，另有独立 mocap 包。

## 本轮落地范围

- 三机：自然移动、蹲趴/跳跃衔接、至少两段空手攻击、重击、受击/倒地；闪避与翻滚为新补充。
- 二号机：新增独立长剑与配套剑击/恢复；原粒子刀模型不被替换。
- 零号机：盾牌准备、持盾、格挡与失衡，完整屋岛剧情仍按用户要求暂缓。
- 初号机暴走：Walk_Large / Zombie 系列只提取合适的弯身压迫、抓击、扑击和动作间衔接，保持TV野兽感；50血触发及剧情保护不变。
- 来源未给出的武器持握、TV12疾跑、第一人称、机库/地图任务仍保留，不用库中近似名称冒充完成。
