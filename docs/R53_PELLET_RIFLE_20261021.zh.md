# 用户提供的新托盘步枪

后续枪托入胸反馈与修复见 `R53_RIFLE_CARRY_20261021.zh.md`。本页15帧的源面／掌心检查没有覆盖胸甲净空；最终持枪位置及交付 SHA 以该后续记录为准。

使用用户提供的 `evangelion-pellet-rifle.zip` 替换本机 `eva_pallet_smg`。新模型和贴图只装入私有客户端；公开仓库提交导入工具、接触点适配和检查，不分发该模型。

## 源模型与材质

`tools/import_pellet_rifle_r53.py` 使用 Blender 的原多边形环三角化，保留5004个源多边形对应的9136个三角面，没有降面、拉伸比例或压低贴图尺寸。统一缩放5.05；坐标系转换计入运行时对 Bedrock X 的反射，实际顶点绕序和法线方向相符。源文件12个零法线角点在退化三角面上，已重建有限法线，原三角面仍保留。

2048×2048底色直接复制，字节哈希与源图一致。AO、法线、粗糙度和金属度转换到 [LabPBR 材质通道](https://shaderlabs.org/wiki/LabPBR_Material_Standard)，没有把金属误设为自发光。法线按 OpenGL 来源转换；这是本次导入参数，不是作者对格式的认证。全部源哈希、比例与转换参数保存在私有 `pellet-rifle1021/candidate-v2/RECEIPT.json`。

## 武器和手部

新资源将枪口、枪托、双手掌心接触点及完整支撑表面绑定到同一模型 SHA。服务器弹道、可见持枪位置和地面净空使用同一组坐标。旧版本没有这些字段的资源继续使用原坐标。

实机近景发现旧手型拟合的平移量仍叠加到新接触点，造成掌心离枪。新接触点改为实际掌心目标，不再应用旧枪的拟合平移；保留手型旋转和旧资源的原有行为。这一修正未改刀、炮等其他装备的接触规则。

零、初、二号机各5个原生样本覆盖站立、两侧近景、蹲姿和趴姿。每帧9136个实际提交三角面均能对应完整源表面，误差小于0.0001格；192个方向的完整网格支撑极值与支撑资源相同。两手实测掌心到目标的最大偏差0.081格。现有渲染根节点约0.05格竖直偏移仍计入枪口误差，没有把它记为零误差。

已查看三机两侧握持近景与趴姿全景。候选前两轮的截图、旧掌心悬空间隙及修后数据均保留。取景只使用客户端临时演员，结束恢复原驾驶员、插入栓和视角；未创建真实任务或替换原机体。城市远景和全身动作美术不属于本项通过范围。
