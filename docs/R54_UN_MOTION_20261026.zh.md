# UN00 与三号机动作接入

本批代码与配套运行资源已安装到当前本地试玩客户端。三号机完成了实际操作检查；UN00 的实际动作检查仍待进行，美术与手感由用户验收。

## 修复

- UN00 已有独立 rig3，但共享地面动作的能力判断一直排除实验机。现在允许自身 rig3 使用跳跃、行走中出拳与上身／下身混合。
- 当前 UN00 运行库只有独立站姿、持枪和爬行，没有专属 walk/run/idle 和步幅接地信息。使用现有初号机完整表演、UN00 实测骨架和原脚底支撑点，生成 idle、walk、run、dash_run 与 11 个普通地面动作，共 1,335 帧。模型顶点、纹理和骨架未改动。
- UN00 护架现在保持握拳，出拳前的闭拳跟随动作时钟；直拳以实测肘腕轴和掌轴对齐，旋前分配到前臂。
- 三号机已有独立自然手，却被旧 `hasOwnUnRig` 判断排除出实测握把路径。服务端枪口计算与客户端双手现在都读取三号机自己的手合同。初号机此前前上移的持枪偏移保持。
- 源三号机不再开启旧 UN01 飞行和目光激光。旧存档若仍在空中飞行，先自动降落，避免加载后直接坠落。保留原实体身份与槽位；UN00 实验机能力保留。
