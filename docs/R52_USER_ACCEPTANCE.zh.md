# R53 地图迁移人工检查

本包完成的是代码修复与构建验证，下面各项实际操作、画面及性能尚待人工验收。首先检查原驾驶员登机后，封舱、收桥和吊机送栓到 EVA 背部能否顺利完成。

使用同批双端和包内 `SEELE_R52_WORLD`；每端只保留一个 Project SEELE JAR。检查本轮地图、发射、机库和快速运输范围。

1. `/seele tp` 列出当前命名地点，通过列表中的机库、观察廊、总部、城市和箱根入口检查迁移。传送目标由当前存档提供。
2. 检查同向方湖与金字塔西南角交叠、外壳与十个实际楼面；逐层沿完整回型通道走到两部主梯，实际乘梯到机库。办公室小梯仍服务办公室。地下通道检查全宽、转角和临空边，退休支路、附着标牌、路口样式与旧机库造型应完整清理。
3. 正常安排原驾驶员登机。管理员用 `/seele eva prepare unit00 geofront` 选一号，`surface` 选二号，`hakone` 选三号；机型参数可替换为 `unit01`、`unit02`。不带目的地时保留作战上下文默认选择。
4. `/seele eva status all` 查看状态，整备后 `/seele eva launch unit00` 发射；整备中 `/seele eva cancel unit00` 取消并沿实轨返回。机库也有整备／状态／取消按钮。
5. 检查三个区先垂直升，二号三号再连续斜升。途中无水平发射长段、通道相交或机体转体，观察电流爆发、摩擦音与接触火花。
6. 检查出口门、真实站位及周边地面。`/seele eva recover unit00` 在对应回收口沿实际路线回库；检查排液坑、桥和密封地板恢复。
7. 获授权的角色电话面板可下达空运／回收；查看原飞机先垂直起吊、空运井开合及任务排队。`/nerv transport status` 查看任务；旧 `force_recover` 不再瞬移或重造迁移机体。
8. 实际乘车检查 GeoFront 地表线路直接下降进金字塔总部站，再升回地表，其余该区站轨保持地表用途；记录车次、往返耗时、进出站画面与原列车身份。实际载荷空运也记录耗时、取消、排队、回收和冷重启后的状态。
9. 核对双端交付回读收据中的导航三缓存哈希、JAR 和实际 World 清单；静态差量、派生导航／导视、玩家、实体、任务与交通进度分别核对。

若因原驾驶员、插入栓、真实支撑或占域而等待，保留状态和现场位置。记录通道、机型、步骤与画面。本清单本身不是人工验收通过记录。
