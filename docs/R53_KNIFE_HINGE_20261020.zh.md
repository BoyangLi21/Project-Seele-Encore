# 持刀攻击髋部扭转修订（2026-10-20）

用户反复反馈持刀攻击时大腿异常分开。原机正常供电、300血的分层记录确认：扭转已经存在于动作源，经过脚底约束后的最终骨架仍保持同样错误，不能靠删减最终大腿角度掩盖。

## 根因与修改

旧重定向用髋、膝、脚三个静止标记的叉积推导膝关节轴。但这三个标记存在横向偏置，推导轴距真正的X轴约78.69°；即便源和目标是同一骨架，也会给大腿引入错误的轴向扭转。

`tools/author_combat_bundle_r44.py` 改用动作实际采用的X膝轴。`tools/repair_knife_hinge_basis_r53.py` 用原Phase-M表演恢复当前三机刀击的大腿参考，并按现有膝轴求解到原脚部目标；保留动作时序、根位移、上半身和脚部位置/方向。三份本地动作配置中的正反两段共897帧已生成并安装。脚位回算最大误差约1e-13模型单位；这个数值只验证保持了原目标，不代表所有动作美术已验收。

只读分层工具增加手动原生姿态录制入口，仍需明确启用 `projectseele.r40PoseLayers`。普通运行不启用记录，也不会启动脚本战斗。
