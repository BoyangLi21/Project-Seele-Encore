## 和 R62 相比

**地图边界**
- 旧的外圈地形（远处那堵“墙”）删掉了，换成新的边界：海这一侧是小田原到国府津的沙滩、真鹤到汤河原的礁石和海蚀柱，骏河湾打开；其他方向是层层叠起的山脊。
- 边界地形由模组自己生成，走到哪里生成到哪里。远景已经预先烘好了外圈约 ___% 的范围，其余部分走近时才出现。

**地图修补**
- 半截埋在山里的机场重做，新箱根机场的平台边缘修整。
- 全图 900 多处地形接缝和林缘补平、补种。
- 道路闭环：三片新城和连接路、辅路、外圈道路，以及大量断头路的截回、接通和封墙。
- 隧道里的平交道口改成下穿，洞壁加了衬砌。
- 贯通线高架上漏铺的道砟补齐；车厢擦到的站台角和道床半砖改掉。
- 浮空和半埋的房子落地或拆除补坡，老建筑门缝补上，大平台边缘改成分级挡墙加草台。
- UN 基地填海地基、零号机平台、芦之湖栈桥和游船、缆车出入口、强罗穿梭线、地下二层的指示牌；UN 旧址清空。
- 横跨贯通线路堑的 NERV 建筑修好。

**列车和电梯**
- 螺旋线限速 700 km/h。高速乘车时列车留在视野里，不再一顿一顿（实测卡顿从 45 次降到 2 次）。
- 金字塔电梯下行不掉人，轿厢在服务器没发数据时也保持住，门框不再闪。
- 城市升降归位后的残影修掉；升降被打断时，管理员可以用 `/seele city recover` 恢复。

**EVA 动作**
- 出击：固定架松开后机体自己承重站稳，落地过渡跟随实际的发射路线。
- 走路和站立：脚掌贴合斜坡和路缘，膝盖只沿铰链弯，摆手不再穿过大腿，攻击收回的距离和冲出去的距离一致。
- 持步枪时辅助手位置、持刀时手臂姿势修正。

**战斗和声音**
- AT 力场在光影下也会发光，每次挡下攻击都能看到。
- `/kill` 和掉进虚空可以穿过使徒的 AT 力场。
- 拉米尔的蓄力、命中、钻头和光束声音换成了负责人挑的版本。
- 缆车车厢有了声音；机库广播在插入栓里有混响，发射更有分量。

**性能**
- 光影下 EVA 和 Create 装置的绘制更快，战斗中最卡的那几帧明显减少。
- 城市升降读取更快，写盘大幅减少。
- 远处没人靠近的载具暂停运算；光影下远处的小实体不投影（客户端设置 `shadows`，默认 64 格和 128 格，填 0 恢复全部投影）。
- 修了 Create 装置在 Starlight 下让客户端崩溃的问题。

**指令**
- 旧写法（`/nerv`、`/un`、`/seele tv`、`/seele tokyo3` 等）已经删除，只剩 `/seele`。
