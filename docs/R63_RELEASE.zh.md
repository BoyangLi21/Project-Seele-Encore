# R63 — 2026-11-13

世界停在第 455 批，代码是 main 60b20f5e。在 R62 的基础上换了地图外圈，修了大量道路、地形和房子，螺旋线高速乘车不再卡，EVA 出击、动作和近战手感做了一轮修正，萨基尔战可以用初号机处决收尾，游戏整体更流畅。

## 和 R62 相比

**地图边界**
- 旧的外圈地形（远处那堵“墙”）删掉了，换成新的边界：海这一侧是小田原到国府津的沙滩、真鹤到汤河原的礁石和海蚀柱，骏河湾打开；其他方向是层层叠起的山脊。
- 边界地形由模组自己生成，走到哪里生成到哪里。远景预先烘好了整个外圈，39,160 段里只有北边最远处零散的 55 段没烘到。

**地图修补**
- 半截埋在山里的机场重做，新箱根机场的平台边缘修整。
- 全图 900 多处地形接缝和林缘补平、补种。
- 道路闭环完成：三片新城和连接路、辅路、外圈道路，以及几百处断头路的截回、接通、封墙和绿化带收头。
- 隧道里的平交道口改成下穿，洞壁加了衬砌。
- 贯通线高架上漏铺的道砟补齐；车厢擦到的站台角和道床半砖改掉；17 个高架桥墩补齐。
- 浮空和半埋的房子落地或拆除补坡，老建筑门缝补上，学校、B17 和大平台边缘改成分级挡墙加草台。
- UN 基地填海地基、零号机平台、芦之湖栈桥和游船、缆车出入口、强罗穿梭线、地下二层的指示牌；UN 旧址清空。
- 横跨贯通线路堑的 NERV 建筑修好。

**列车和电梯**
- 螺旋线限速 700 km/h。高速乘车时列车留在视野里，不再一顿一顿（实测卡顿从 45 次降到 2 次）。
- 金字塔电梯下行不掉人，横移换井层时人不再掉 1 格；轿厢在服务器没发数据时也保持住，门框不再闪。
- 城市升降归位后的残影修掉；升降被打断时，管理员可以用 `/seele city recover` 恢复。

**EVA 出击**
- 固定架里僵住的时间从约 2.65 秒缩到约 1.65 秒：载台下放和关井口门同时进行。
- 固定架松开后机体自己承重站稳，落地过渡和第一人称视角跟随实际的发射路线。
- 驾驶中不能再被传送走（以前会让机体在驾驶员这边掉回发射井）。

**EVA 动作**
- 走路和站立：脚掌贴合斜坡和路缘，脚下的着地点按实际模型取；膝盖只沿铰链弯，摆手和空着的手不再穿过大腿。
- 攻击：打完停在冲到的位置，不再被拉回原地；刀刃会翻起来避开地面；零号机举不稳盾时盾牌靠在脚边。
- 倒地和起身：匍匐时肚子、膝盖和前臂贴地；倒地的机体速度有上限，不会被萨基尔弹飞；起身交回动作时不再跳帧。
- 持步枪时辅助手位置、持刀时手臂姿势修正。

**战斗**
- 闪避可以打断已经出完的攻击，也能在对方出招一开始时闪开。
- 镜头按打击的分量晃动，抓住对方时持续震动。
- 萨基尔战满足条件时，每一场都能由初号机处决收尾，砸下的拳头落在核心上。首战一开始萨基尔就和初号机分开，首战镜头不再穿进两具身体。
- AT 力场在光影下也会发光，每次挡下攻击都能看到。
- `/kill` 和掉进虚空可以穿过使徒的 AT 力场。

**声音**
- 拉米尔的蓄力、命中、钻头和光束声音换成了负责人挑的版本。
- 缆车车厢有了声音；机库广播在插入栓里有混响，发射更有分量。

**性能**
- 光影下 EVA 和 Create 装置的绘制更快，战斗中最卡的那几帧明显减少。

- 远处没人靠近的载具和防空炮暂停运算，有敌对目标靠近时照常恢复。
- 光影下远处的小实体不投影（客户端设置 `shadows`，默认 64 格和 128 格，填 0 恢复全部投影）。
