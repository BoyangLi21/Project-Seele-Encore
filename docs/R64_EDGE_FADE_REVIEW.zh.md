# R64 地图陆地边界渐变

地图外侧由 GeoFront 生成器生成。第 539 批修过城北一段，本次核对 R63 的三个存档连通域，按各处实际地表推广同样的内侧渐变。范围依照 R63 存档区块轮廓，写入维度为 `projectseele:geofront`。

## 交审数据

54 个非空区域批次，共 300,520 列、882,674 格。逐列最多写 8 个不同方块，地表升降最大 7 格。城北试点 63,919 格在冷副本上全部符合第 539 批新状态，本次与其重合 0 格。行格式为 `[x,y,z,before,after]`。每个 MCA 区域单独一个 JSON，由区域坐标唯一归属。

- 清单和 MD5 在 `D:/eva-codex-edge-fade/batches.json`。有 `file` 的条目对应 `rows/<file>`。其余区域经检查无可写格。
- 完整冷副本、试写回执、同区域写前备份分别在 `world/`、`trial/r.<rx>.<rz>/installation.json`、`trial/r.<rx>.<rz>/*.mca`。每批使用当前主分支的 `tools/write_deep_cells.py --world <完整副本> --rows <区域清单> --out <新的备份目录> --refresh-heightmaps`。正式写入前沿用工具的旧状态预检。
- `images/north.png`、`east.png`、`south.png`、`west.png` 从写前备份和已写副本重新解码，展示四个朝向的地表和跨界剖面。`images/limit.png` 展示单列上限保留的断崖。外侧尚未存进正式世界处采用专服已经生成的真实区块。图为离线高程图，游戏内观感留给负责人。
- 全部 6,113 个两侧为自然地面且本次改变的跨界方块面都缩小了高差，均值由 5.28 格降至 2.32 格，至少 4 格的面由 2,264 降至 931。高差最大的一处由 44 降至 37，受单列上限约束，仍应单列人工审看。

## 计算范围

按 R63 的 116,665 个有记录区块，检查三块连通地形及内部孔洞。7,186 个区块在内侧 64 格带中满足可写条件，其中 6,537 个为 FULL，624 个已完成 features 或在光照、出生阶段，另有 25 个 carvers 在生成完成的参照世界中可逐列、逐状态核对。所有 5,965 个相关外侧参考区块都实测为 FULL。两个分离域（3,864、243 个区块）的边缘 64 格只有结构起点或生物群系记录，尚无已建地表。主连通域中另有 11 个 carvers 缺少完成态参照，保留原状。按现有地面筛查，其中 6 块没有候选，其余 5 块合计 287 列潜在变化，均在边界内侧至少 33 格。详见 `pending-carvers.json`。

专服旧外圈任务的 12,588 个目标中，12,506 个在专服存档里确认为 FULL。其余 82 个没有影响可写区域的实际外侧取样。全图另核对过区块角落和分离域。此次复用既有生成结果，未启动地图客户端或专服。

## 参数与保护

先按方块到边界的欧氏距离，对内侧 64 格做 smoothstep 渐变。目标面使用两侧自然地面高程的归一化高斯滤波（σ 14 格，支持半径 56 格）。水、树冠和建筑顶不参加平滑。边缘仅向实测外侧高程移动，角点同时满足两面的区间约束，向内 16 格逐步解除该约束。接到不可写段、海岸或已验收的城北试点时，沿边界渐隐 32 格。连续边界跨越区域文件时保持同一计算窗口。

自然地面采用城北试点的草、土、苔、石、砾石白名单。树、水、沙、道路、建筑及其周围两格（含对角）保留。实际升降涉及受保护地下方块或上方地物时整列跳过。允许移开的矮植被按整株处理。carvers 必须同时有生成完成参照，待改格的旧状态须逐格相符。与道路清单冲突时整列保留。每列唯一变更格数与地表高度差同时受 8 的上限约束。

## 重算

```powershell
& $frpy tools/plan_r64_edge_fade.py --world <当前完整冷副本> --r63 <R63基准副本> --generated <专服已生成副本> --extra <补充完整区块参照> --roads <道路清单> --out <新的空目录>
```

所需库为 numpy、scipy、nbtlib。地表参考采用 `D:/eva-seam/server/EDGES`，R63 基准为 `D:/eva-ringbake/lzma-test/world-base`，3 个补充完成态采样来自 `D:/eva-ringbake/client/saves/MAP_REVIEW`。本次完整冷副本有 80,725 个文件，复制失败 0。脚本只生成清单，区域写入交现有安装工具。

写入影响 GeoFront 的地形远景。R64 发布远景需在正式安装后用变更区域及相邻瓦片的真实区块重烘，刷新对应父级缓存。旧正式世界里的平顶远墙源自早期 Distant Horizons 库，此清单不含远景数据库。检查近景和远景过渡需使用重烘后的库。
