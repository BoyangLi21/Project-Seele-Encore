# 死海文书分支与下一章的可玩设计

本分支是项目原创。TV 第五、六话的未知反击条件、城市收纳、电网调度及两机协作为制作依据；没有把自创档案、技术员或复测流程称为原作情节。既有 TV 战役完成记录与这份调度档案分别保存。

## 当前原创准备分支

每份档案有独立 UUID、司令 UUID、已阅证据、共享范围、供电方案、编成和驾驶员确认。开始新档案不清除玩家已取得的原始资料。旧页面的撤销或确认不能操作新的档案。

| 步骤 | 玩家实际操作 | 世界条件与失败出口 |
|---|---|---|
| 接受 | 在电话联络美里，打开城市协同档案 | 作战进行中不得抢占城市或发射设备；没有设备配置不得开始 |
| 核对 | 分别查看原页、译注、现场记录，决定是否共享 | 记录区分保管来源、SEELE 的主张与 MAGI 的测量；没有读完三项不得推进 |
| 收纳 | 选择应急设施保电或蓄能优先，由冬月下达城市收纳 | 等待实际建筑到达地下终点、没有未完成搬运游标和设备故障；不是延时后直接改任务状态 |
| 复测 | 委派远山，或乘车到地区技术中心亲自采样 | 管制员真实走到按键前，隔离备用馈线；现场方案还必须实际按键并在设备前取得连续稳定读数 |
| 复电 | 远山再次操作设备，接回馈线 | 应急供电、隔离状态、任务身份与操作者都重新检查；读数失败不得进下一步 |
| 供电 | 保留应急设施供电，或切出备用馈线充能 | 两方案分别等待 800 / 400 tick 的有效充能；掉电或开关与方案不符暂停并重计 |
| 编成 | 选择机体、人类或对应驾驶员，逐台确认 | NPC 必须已经收到三项资料；每台单独同意或撤回。确认编成不意味着获得发射许可 |
| 归档 | 由司令确认准备结果 | 必须完成复测、供电及全部驾驶员确认；仅归档准备结果，不生成使徒、发射机体或改 TV 通关记录 |

现场复测柜位于地区技术中心南侧站厅，操作高度 Y=119。到站后使用真实跨线天桥前往；禁止直接穿越轨道。按钮在 (-1074,120,571)，柜体有落地底座和隔离指示灯。乘客通道、真实客户端按键和采样中断尚未实测完成时，配置中的开放标志必须保持关闭。

采样须同时满足：当前档案由操作玩家负责、人在设备前、有 NERV 权限卡、备用馈线隔离、应急馈线带电、按钮仍存在。离开、掉线、取消或馈线被改动均不能继承一个已中断的采样。复电由真实岗位技术员完成，不用服务器瞬间切换开关冒充角色操作。

取消时撤销继续充能和后续指令，恢复备用馈线并保存已阅证据。三处取消窗口分别为收纳中、隔离采样中和充能中；建筑安全停靠与电网复原独立报告，不因一句“已撤销”掩盖设备尚未完成。

## 下一章：第五使徒／屋岛作战

以下是完整制作设计，尚不能当作已完成的游戏章节。原作顺序保持萨基尔 → 夏姆榭尔 → 雷米尔。已有拉米尔战斗原型和本轮原创准备档案不是完整屋岛作战成品。

| 状态 | 进入条件与玩家行为 | 对手、同伴及可恢复结果 |
|---|---|---|
| 信号出现 | 玩家选择下一章；指挥室、机库报警，操作员文字报告未知高能目标 | 仅出现目标和警戒区，不直接扣任务生命或启动全部 EVA |
| 初次接触 | 玩家或 AI 选择一台出击，其他机体仍可支援 | 拉米尔预备反击有清楚的光线、声音和攻击方向；第一次失利提供实测反击资料，损毁机体保留真实倒地姿态 |
| 回收与核对 | 玩家呼叫运输回收、回到指挥室，与律子检查所得测量 | 飞机按当前机体姿态装载，运输姿态与放下连续；损毁机体维修达到完整准备条件后才可再次出击 |
| 作战提案 | 美里提出远距狙击，司令选择是否执行及供电方案 | 冬月负责城市、电网技术员负责馈线，驾驶员确认自己的射击或掩护职责；警卫没有作战权限 |
| 屋岛部署 | 一台狙击、一台掩护，可由玩家或对应 NPC 驾驶；运输与正常发射可选 | 炮、供电接头、护盾或替代防护设备先实际部署。没有装备或供电不得进入倒计时 |
| 测距与试射 | 玩家瞄准，操作员给出环境和蓄能状态；AI 根据同一射击条件操作 | 命中只按实际弹道与核心窗口判断。首发偏差是可读取的战斗事件，不能用预设血量直接算命中 |
| 敌方反击 | 拉米尔定向反击狙击机体，掩护驾驶员选择挡击或撤离 | 掩护机先移动到实际拦截位置，再承受冲量和损伤；挡击失败不能显示一段成功动画却没有实际保护 |
| 第二次充能 | 司令决定继续、换机、支援或撤退；玩家可以换到掩护或射击岗位 | 电网、炮冷却和驾驶员状态分别复核。中途加入的 EVA 使用同一战役身份，不能另起一个敌方实例 |
| 核心击破 | 玩家或 AI 在有效窗口实际命中 | 核心受击与倒塌有连续动作、重力和地面接触；不复用萨基尔的抱持自爆，也不提前生成十字架核爆 |
| 救援与归档 | 回收受损机体和驾驶员，进行维修、复电，返回指挥室 | 玩家可选择救援顺序。只有核心击破、关键驾驶员状态已处理和设备归档后才记下一章完成 |

射击、支援、撤退及回收都经过同一套任务身份和岗位权限。玩家关闭任务时，不再自动 prepare 或发射；已经发射的机体转为可回收状态。死亡、离线、服务器重启、当前司令变更都要有明确续接或撤销路径，不重复生成炮、运输机、使徒或驾驶员。

## 交付门槛与现状

准备分支原先的委派隔离、存盘及冷启动续接有 14 项原生检查通过；本次新增真实角色复电与现场采样后，这部分证据只算旧版本有效继承，必须重新实测。当前尚欠现场两侧站台到设备的实际步行、客户端按键、稳定与中断采样、应急保电支路、三类取消窗口、NPC 编成、多玩家权限和最终安装副本检查。

下一章仍欠原作镜头／设备参考逐项映射、完整可操控双机战斗、掩护接触、运输救援与归档。没有用长对白或大量新使徒填充这段，也不把设计文档算作可玩完成。
